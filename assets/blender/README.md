# Blender 原創素材與可重建來源

2026-11-16。目前包含一位成年男性類型居民、陶罐、石製杯皿，以及會幕的織線樣本、板座接合局部與洗濯盆，共六份 GLB。不是掃描文物或精確服裝復原，也不宣稱已完成全部角色與十四項器具。

## 製作與重建

- 使用官方 Blender **4.5.16 LTS** Linux x64（build `3f6797307da5`）。[官方發行目錄](https://download.blender.org/release/Blender4.5/) 與 [校驗檔](https://download.blender.org/release/Blender4.5/blender-4.5.16.sha256)。本輪下載包 SHA256：`23432b064977908beb1ab4b7f32f024e7331105c875c187dce002aff84b10c11`。
- 由本專案腳本建立曲面、骨架、權重、衣褶、五官、手指與器皿內壁；沒有使用第三方網格、貼圖、人物掃描或雲端模型服務。
- `bible-assets.blend` 有六個獨立素材場景，含可編輯網格與骨架。預覽燈光／相機在存檔與匯出之後加入，不混入 GLB；GLB 僅匯出活動場景與所需階層，沒有裝入其他素材。

在專案根目錄執行（`BLENDER_BIN` 指向官方執行檔）：

```bash
"$BLENDER_BIN" --background --factory-startup --python scripts/blender/build-assets.py
```

輸出 `public/models/*.glb`、本資料夾的 `.blend` 與 `build-report.json`，以及忽略於 Git 的 `.qa/blender-*.png`。GLB 內含所有幾何、材質、頂點顏色與骨架動畫，不使用外部貼圖；Three.js 直接讀取同一份匯出。建置報告記錄實際 bytes、三角形數、動畫與 SHA256。

會幕素材由同一流程執行 `scripts/blender/tabernacle-props.py`，保留木板／雙銀座階層供拆合；不需第三方外掛。回歸直接讀取匯出 GLB，核對單一場景、空心盆／卯孔、比例、幾何預算、動作與檔案雜湊。骨架與材質節點仍可在 Blender 編輯。

## 比例及史料界線

Blender 使用公尺，正面為 -Y；glTF 轉成 Y 向上、+Z 朝前。居民站姿約 1.70 m，陶罐高 0.548 m、石皿 0.328 m，後兩者是教學選定尺寸，沒有宣稱來自某件文物的測量。

居民以短袖束帶長衣、矩形披布、皮帶與涼鞋作日常服裝的初步研究。可比對以色列文物局 [Nahal ʽArugot 紡織物發掘報告](https://hadashot.iaa.org.il/report_detail_eng.aspx?id=25101&mag_id=124) 的材料與工法。報告涵蓋不同時期，部分可比資料晚於第一世紀；本模型的剪裁、衣色、髮型及臉孔均屬選擇，不能當作每位猶太居民的固定裝束。舊約、祭司、婦女、孩童及特殊職分不可直接套用。

石器的時代及工藝背景可對照文物局 [Jerusalem, Har Ḥoma 發掘報告](https://hadashot.iaa.org.il/report_detail_eng.aspx?id=26607&mag_id=139)。模型未複製報告圖版或任何單件器形；垂直加工紋與陶罐提耳都是類型化的製作選擇。用途、潔淨觀念與家庭身分仍須回到資料判讀，不能由造型直接認定。

| 素材 | 依據 | 模型補足與使用界線 |
| --- | --- | --- |

| 板架與雙銀座 | [出 26:15–30](https://www.bible.com/zh-TW/bible/312/EXO.26.CSBT) 的木板、兩榫、兩銀座、包金與閂 | 高 0.846 m，只展示板架下段。局部金覆面打開以露出木芯；銀座卯孔、木紋刻畫、短閂、拆開 0.18 m 的距離皆是現代教學選擇，不拿這個局部比例推算完整板的肘數。 |
| 洗濯盆與盆足 | [出 30:17–21](https://www.bible.com/zh-TW/bible/312/EXO.30.CSBT) 的銅盆、盆座及服事前洗濯用途 | 高 1.24 m 是本專案的陳列尺度，經文未提供完整尺寸。連續內外壁、口緣、盆足與表面加工痕為形制選擇；不借用銅海的十二牛、百合花或其尺寸。場景本體與近景使用同一 GLB。 |

經文連結維持 YouVersion CSBT。模型不新增經文引文或宣稱考古原物。金覆面剖切、支架與放大織紋的說明已放在使用者可讀的器物觀察內容，避免只在工程文件註明。

## 本輪使用範圍

- 耶路撒冷近距離成人一般居民，最多八位，22 m 進入／25 m 退出細節範圍並保留選擇滯後；遠處沿用原有批次輪廓。
- 搬水居民、孩童及其他四座詳細島暫不套用，等待持物、年齡與服裝相應素材。
- 耶路撒冷院落兩件器皿、會幕三件觀察物與旋轉近景共用 GLB；讀取失敗仍能觀察相應模型。其餘九件觀察物仍待製作。
- 每位可見居民擁有獨立骨架與 mixer，從自己的原有狀態／時鐘取樣五種動畫；POI、seed、避讓、對話與進度資料仍由原系統處理。

這是實際 Blender 管線與逐批素材替換，人物視覺仍有風格化特徵。下一輪需改善臉部、衣料的材質層次、衣袖／手部接合、步態足底接觸與人物差異，擴充年代／職分變體並接續其餘九件器具。尚未取得獨立歷史專家、美術專家或實體手機驗收。
