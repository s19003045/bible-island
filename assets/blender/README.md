# Blender 原創素材與可重建來源

2026-11-16。目前包含二十八種人物、十一島三十二項觀察物及一種羊，共六十一份 GLB。十一座詳細島嶼的近處人物接入骨架素材；三十一項實體展品同時在場景使用，渡海剖面供近景比較，大場景保留水體與動態隊伍。不是掃描文物或精確服裝復原，人物仍有風格化特徵；其餘十三島尚未升級。

## 製作與重建

- 使用官方 Blender **4.5.16 LTS** Linux x64（build `3f6797307da5`）。[官方發行目錄](https://download.blender.org/release/Blender4.5/) 與 [校驗檔](https://download.blender.org/release/Blender4.5/blender-4.5.16.sha256)。本輪下載包 SHA256：`23432b064977908beb1ab4b7f32f024e7331105c875c187dce002aff84b10c11`。
- 由本專案腳本建立曲面、骨架、權重、衣褶、五官、手指與器皿內壁；沒有使用第三方網格、貼圖、人物掃描或雲端模型服務。
- `bible-assets.blend` 有五十八個非空素材場景，含可編輯網格與二十八套獨立人物骨架。預覽燈光／相機在存檔與匯出之後加入，不混入 GLB；GLB 僅匯出活動場景與所需階層，沒有裝入其他素材。

在專案根目錄執行（`BLENDER_BIN` 指向官方執行檔）：

```bash
"$BLENDER_BIN" --background --factory-startup --python scripts/blender/build-assets.py
```

輸出 `public/models/*.glb`、本資料夾的 `.blend` 與 `build-report.json`，以及忽略於 Git 的 `.qa/blender-*.png`。GLB 內含所有幾何、材質、頂點顏色與骨架動畫，不使用外部貼圖；Three.js 直接讀取同一份匯出。建置報告記錄實際 bytes、三角形數、動畫與 SHA256。

開發伺服器忽略 `.qa`、`.sites` 與 Blender 來源；GLB 保留檔案監看，以便 Vite 登錄啟動後才新增的素材，但 `hotUpdate` 不觸發模型整批匯出的頁面重載。匯出完成後手動重載檢視頁一次，JavaScript／CSS 仍保留熱更新。不能把 `public/models` 整個排除監看，否則新增 GLB 會被 SPA 的 HTML 回應取代。此行為已有真正臨時 Vite 伺服器、啟動後新增／更新檔案及 HTTP bytes 的回歸檢查。

會幕素材由同一流程執行 `scripts/blender/tabernacle-props.py`，保留木板／雙銀座階層供拆合；不需第三方外掛。回歸直接讀取匯出 GLB，核對單一場景、空心盆／卯孔、比例、幾何預算、動作與檔案雜湊。骨架與材質節點仍可在 Blender 編輯。

所羅門素材由同一流程執行 `scripts/blender/solomon-props.py`。十二隻鑄牛保留各自的階層與方位，香柏內襯保留可拆合的群組；測試以真正網格的相連面計算石榴，並以射線核對牛背承托與盆內底，而非僅信任建置報告宣告的數量。

## 比例及史料界線

Blender 使用公尺，正面為 -Y；glTF 轉成 Y 向上、+Z 朝前。居民站姿約 1.70 m，陶罐高 0.548 m、石皿 0.328 m，後兩者是教學選定尺寸，沒有宣稱來自某件文物的測量。

居民以短袖束帶長衣、矩形披布、皮帶與涼鞋作日常服裝的初步研究。可比對以色列文物局 [Nahal ʽArugot 紡織物發掘報告](https://hadashot.iaa.org.il/report_detail_eng.aspx?id=25101&mag_id=124) 的材料與工法。報告涵蓋不同時期，部分可比資料晚於第一世紀；本模型的剪裁、衣色、髮型及臉孔均屬選擇，不能當作每位猶太居民的固定裝束。舊約、祭司、婦女及特殊職分不可直接套用；孩童的身形與短衣另作教學選擇，沒有單件第一世紀兒童衣物的複原主張。

石器的時代及工藝背景可對照文物局 [Jerusalem, Har Ḥoma 發掘報告](https://hadashot.iaa.org.il/report_detail_eng.aspx?id=26607&mag_id=139)。模型未複製報告圖版或任何單件器形；垂直加工紋與陶罐提耳都是類型化的製作選擇。用途、潔淨觀念與家庭身分仍須回到資料判讀，不能由造型直接認定。

## 成人細化與步態

`scripts/blender/resident-refinement.py` 補充肩口、手腕／肘部、臉部曲面、腳掌、腳趾及分層皮底；一般居民保留矩形披布，工藝角色實際移除該披布，不只改色。短衣長度、臉孔與衣裝組合為原創人物類型，不宣稱古代職業制服。皮底與繫帶可比較 [Library of Congress／IAA 的昆蘭皮革展品](https://loc.gov/exhibits/scrolls/art2.html)，模型的繫法與約 0.28 m 腳掌尺度不是該館藏原物的精確複製。

Blender 烘焙五種動作；Walk 為一秒週期，58% 支撐期、42% 抬腳期及短暫雙腳支撐，兩骨解算保持踝部軌跡，匯出移除首幀偏移。執行期用實際移動距離推進步態，相互獨立的 NPC 時計仍負責其他動作；沒有新增共用決策計時器。足部 IK 依物理地面法線調整支撐腳及骨盆，對平地、上／下斜坡的實際腳底網格做接觸與滑移檢查。混合前恢復未施加 IK 的骨架，避免暫停時重複累積偏移；離開細節範圍釋放各自的骨架紋理。

五座詳細場景皆選取相應近距離人物：耶路撒冷及希律保留一般成人、無披布工藝成人、孩童與提水者；會幕、所羅門及出埃及使用下述新衣裝。每場景最多八位近距離細節，22／25 m 滯後。一般人物 0.33 m 乘個體身高比例，提水居民 0.49 m 的避讓半徑包含側邊器皿，不隨 LOD 改變。模型仍有風格化特徵。

## 孩童與持物

`scripts/blender/resident-variants.py` 建立兩套獨立骨架／網格與各五種動作。孩童高約 1.10 m，頭、軀幹、腿與肩寬採不同縮放，再獨立重塑顱頂、臉頰、小下顎、鼻、嘴唇與眼眉；不是把成人等比例縮小。身高與約 0.20 m 頭部是教學選定值，不用來推定某個年齡、民族人體統計或古代平均身高。短衣、皮底與面容皆為原創選擇。

孩童的一秒步態依較短的腿長烘焙，參考水平距離約 0.4903 m；執行期以實際行走距離決定週期，保留原 NPC 的個別速度和決策。足部 IK 使用自己的踝高 0.075 m 與抬腳幅度，實際皮底頂點通過平地、上下坡及支撐期滑移檢查。

提水居民另有右臂的彎肘休止姿、拇指對握及四根彎曲手指；空心陶壺有實際內底、厚口緣與一只提把，高 0.39 m。手掌、指節與壺體共用持物手的變形骨，行走與對話時維持接觸；左手仍能擺動與示意，不假演放下或倒水。陶器背景可比較 [Library of Congress／IAA 昆蘭器物](https://loc.gov/exhibits/scrolls/art2.html)；這個壺形、尺寸、容量、側提方式及居民路線都是教學設計，不能由其他儲藏罐的出土用途認定本壺。沒有指定為福音書某位提水者，也未改寫既有台詞／錄音。

## 本輪使用範圍

- 七座詳細島使用相應年代／職分素材；每場景最多八位近距離細節，22 m 進入／25 m 退出範圍並保留選擇滯後，遠處沿用較輕輪廓。
- 婦女、孩童、曠野家庭及舊約職分已按上表接入；約旦河另有四位持槓祭司，依站立階段維持右手與槓的接觸。
- 五島十四項觀察物都有 Blender 近景，其中十三項同時在場景使用；渡海大場景保留水體與動態隊伍，剖面只供近景。所羅門的兩座大柱頂和銅海本體也使用相應素材。讀取失敗仍能觀察及拆合相應備用模型。
- 每位可見居民擁有獨立骨架與 mixer，從自己的原有狀態／時鐘取樣五種動畫；POI、seed、避讓、對話與進度資料仍由原系統處理。

這是實際 Blender 管線與逐批素材替換。臉部及衣料仍可繼續細化，其餘十七座詳細島嶼仍待完成；既有素材也可持續細化。尚未取得獨立歷史專家、美術專家或實體手機驗收；希律三件近景及渡海剖面的完整手動走訪仍待補驗，不能只由測試數字推定全體美術／操作驗收完成。

## 約旦河素材

持槓祭司使用自己的骨架與彎肘、彎指、連續袖面；場景四人立在乾地，手部維持接觸槓身，獨立取樣停留動作。約書亞記 3:17 的站立階段不演成居民閒逛。此模型不冒稱精確古代服裝；距離與吉甲位置也未按考古測繪，見 [約旦河驗收](../../docs/review/JORDAN-WALK.md)。

## 亞伯拉罕三章新增素材

旅人、家中居民與井邊照顧者各有獨立骨架及五種動作；新披布、長衣與前面鬍鬚為選擇性設計，沒有指認亞伯拉罕或撒拉的肖像。旅人披布改為後肩面，避免走路時手部穿透；仍有風格化特徵。

## 約瑟與埃及（第十座）
