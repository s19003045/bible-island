# 耶路撒冷生活：三角色動作參考

本目錄保存 **10 個未改寫的 CMU 動作片段**、原生 ASF／AMC、固定版本 BVH 轉換、官方索引與授權文字，以及唯讀量測。總量約 16.2 MB，沒有下載完整資料集壓縮檔。一般步行與慢走繼續引用既有的 `assets/blender/jerusalem-pilot/reference/07_01.bvh`、`07_04.bvh`，沒有修改或另行宣稱其角色身分。

- [CMU 官方 FAQ](https://mocap.cs.cmu.edu/faqs.php) 允許複製、修改及再散布動作資料。[官方首頁](https://mocap.cs.cmu.edu/) 亦說明可供各種用途使用。這是資料集的許可文字，**不是 CC0 或具名 SPDX 授權**。
- BVH 為 Bruce Hahne 的轉換，固定下載版本為 [`una-dinosauria/cmu-mocap@09a07f54f3bbb58797325f009282d0b2048a2871`](https://github.com/una-dinosauria/cmu-mocap/tree/09a07f54f3bbb58797325f009282d0b2048a2871)。未更動的 `READMEFIRST.txt` 保存轉換者的許可與限制。
- 致謝：CMU Graphics Lab；mocap.cs.cmu.edu；NSF EIA-0196217；BVH conversion Bruce Hahne（2010）。
- **手指／拇指關節是為編輯方便而加入，並非實際捕捉。** 握持、手指接觸、道具附著、負重反應與時代服裝均需自行製作。
- 這些是現代一般人體動作參考；沒有本次三位歷史角色、兒童或長者真人的捕捉，也沒有已確認重量的水罐負載。`07_04` 只是慢走，不可標成長者真人捕捉。
- `79_25` 的官方描述涉及移動箱子，但沒有可直接供水罐使用的已追蹤箱體或已核實重量；`143_10` 是現代工具箱拾取身體動作，並非歷史提水動作。

`source-downloads.json` 記錄每個檔案的確切 URL、固定版本、位元組數與 SHA-256；`measurements.json` 另驗證所有原始參考在量測前後 SHA 相同。CMU 官方 HTTPS 端點目前無法通過憑證驗證，因此保存其可用 **HTTP** 官方頁面／原生資料；固定 GitHub BVH 鏡像使用正常驗證的 HTTPS。沒有停用 TLS 驗證。

## 重要的時間與座標差異

1. **BVH 第 0 幀是轉換者加入的 T pose，不能播放。** 原生 AMC 第 1 幀對應 BVH zero-based index 1。下表範圍包含兩端，時間為 `(frame−1) / effective_fps`，時長為 `(end−start) / effective_fps`。
2. **Subject 79 必須採官方索引的 60 Hz。** 轉換者將所有 BVH 標頭統一寫成 `.0083333`（約 120 Hz）；但 `79_16`／`79_25` 的官方索引為 60 Hz，且原生 AMC 樣本數正好等於 BVH 減去 T pose。不可直接照其 BVH 標頭倍速播放，也不要改寫原始參考檔。
3. 其餘本次片段的官方索引為 120 Hz。資料來源單位換算採官方公式 `(1 / .45) * 2.54 / 100` 公尺／單位；人物重定向仍須依原始肢長重新校準。
4. 量測使用既有唯讀 BVH parser：反射 X，原 Y-up／+Z 前進轉為 Z-up／−Y 前進。故左轉在此座標通常呈負 yaw；不可未映射便套成 runtime 的旋轉符號。

左手相對骨盆最低為 frame 182（−0.510 m），最高為 frame 118（−0.092 m）。右手並未同樣觸地：相對骨盆最低 frame 268（−0.127 m），最高 frame 390（−0.0075 m）。因此，現有右手提罐角色必須有意識地鏡射／交換左右，或自行設計右臂與道具工作空間約束。

第二事件 frame 369 之後雙腳都有運動學接觸候選。可以把獨立的上半身降低曲線反向／重新定時，配合自製站定腿部與道具接觸來做 Pick／Place；**那是自製的放物改編，不是直接捕捉的放物**。不可反播整段走路根運動，否則會倒走與倒轉。

## 接觸與角色化限制

`*-measurements.csv` 提供幀號、根節點軌跡、heading、速度與接觸候選；這些是腳踝／腳趾位移及局部高度推估，**不是力板真值，也不是新人物腳掌幾何的接地驗證**。原始 foot/toe 資料有雜訊，重定向後仍須地形 IK、腳掌接觸與步幅匹配。

居民的 Inspect／Receive／PlaceSmall、攤販的 Arrange／Offer 可引用 `79_16` 的身體與速度節奏，再把手約束到實際商品／桌面。提水者可引用 `143_10` 的髖部與脊柱時序，保留正確握持側、腳支撐及道具附著時機。長者仍以一般慢走資料做角色化改編；沒有長者真人動捕或歷史人物動作可供宣稱。專門的普通 StartWalk 未由本次資料確立，從站姿銜接起步仍需標為自行製作。

材質／道具的有限考古依據與不可推論事項另見 [historical-material-notes.md](historical-material-notes.md)。
