# 耶路撒冷人物動作試點

本次只替換耶路撒冷三位可交談角色：院落住戶、提水居民、年長街邊商販。保留角色 ID、原有服裝幾何／表面顏色、對話、學習進度與遠近一致的衣裝。其他 28 種原模型沒有重建，其他島的角色映射維持原狀。

## 真實來源與改編範圍

一般居民與提水者以 CMU 07_01 成人步行、年長者以 CMU 07_04 成人慢走資料為基礎；120 Hz 重定向、去除根位移並補齊循環。提水承重與長者姿態是作者改編，不是實際捕捉提水者或高齡者，更不是古代人物的動作紀錄。骨架／動作改善並不等於寫實臉部或完整布料模擬；年長商販仍使用原工作者的臉部與衣裝。

資料集來源、原始 ASF／AMC、BVH 轉換、授權頁存檔、來源雜湊與單位換算均在 `assets/blender/jerusalem-pilot/reference/`。CMU FAQ 允許複製、修改與再散布；BVH 轉換者沒有新增用途限制。資料來自 mocap.cs.cmu.edu，原資料庫受 NSF EIA-0196217 資助。

- 可編輯來源：`assets/blender/jerusalem-pilot.blend`，約 11.7 MB，三個場景。
- 生成：`scripts/blender/jerusalem-pilot.py`；匯出後執行 `node scripts/prepare-human-motion.mjs`，檢查 SHA 並同步 runtime 與全站資產報告。
- 實際素材／渲染審查：`assets/blender/jerusalem-pilot/review.md`、`validation-report.json`。

## 動作與行為

- 骨架新增有實際權重的多節脊柱、鎖骨、腳趾、自由手指、眼睛、眼皮與衣物關節。保留提水右手與水罐共用的握持關係。
- `human-navigation.js` 沿已保留的 POI 安全路線前看，以連續弧線轉向；急轉先煞車。身體角速度受限，渲染器不改控制器位置或朝向。
- `human-locomotion.js` 依實際距離推進步態，配合個體速度在有限範圍調整步幅與節奏。起步採距離對應、停步／轉身採單次播放；中斷時保存外出姿勢，短暫衰減姿勢差，不突然重播起步或急切換。
- `resident-foot-plant.js` 對試點採樣包含腳趾混合蒙皮在內的完整變形腳掌，分辨腳跟、全掌與腳尖支撐，保留擺動腳抬起的高度；地面正常方向與雙腿 IK 同步處理坡面。
- `human-performance.js` 以獨立視覺種子處理路線注意、交談對象、短暫看向附近旅人、眨眼及站立姿態微調。眼睛先動、頭與軀幹稍後跟上；提水者上身轉幅較小。衣物只做受轉向與加減速驅動的有界阻尼反應。
- 原 POI 加權選擇、容量保留、個人種子／決策計時、速度差、社交冷卻及 20% 短暫交談規則維持。沒有增加群體共用決策時鐘或 Random Walk。
- 最多八位近景完整解算，對話及近距離視野內的試點人物優先；遠景沿用同骨架、衣裝與配件，僅降低骨架取樣及幾何量。

## 使用與比較

進入「新約耶路撒冷」→「比較人物步態」。可選一般居民／提水居民／年長商販，以及街道直行、街角、停步折返、階梯、與居民錯身、交談六種測試路線。前後兩版共用一個真實 NPC 控制器、相同速度與路線，但各自保有視覺相位。並排模式以分隔繪製區避免側面人物或樓梯互相遮住；暫停、重播、正面、側面及拖曳視角皆可操作。

這些是觀察用小路線，不會改變正式場景的學習或 POI 規則。避讓路線的對照居民為靜止的實際碰撞／分離代理，交談路線會定時示範停下交談。

## 驗證

`tests/human-motion.test.js` 直接讀取三個真實 GLB，檢查有效骨架權重、捕捉來源、動畫長度、完整腳趾接地、上下坡面、控制器不可被動畫改動、六種路線實際抵達、階梯往返、轉角／個人空間、暫停與獨立視覺隨機、近景名額、提水握持以及起停／交談中斷。

素材離線 121 個小數相位檢查最低腳掌高度分別為 +0.244／−0.490／−0.015 mm（runtime IK 前），循環端點關節位置及旋轉差皆零。runtime 測試另對完整變形腳掌、坡面與過渡動作驗證；這些數值不等於所有地形或裝置均已人工驗收。

實際瀏覽器已檢查三角色切換、正面／側面、新舊並排與提水階梯介面，並修正側面遮擋問題。全站測試、正式發佈與限制的最後結果另記 `docs/DEPLOYMENTS.md`。

全站 60 個測試檔／352 項通過（59 檔／351 項完整回歸，加上原樣重跑的 1 項本機伺服器測試）。該伺服器測試首次受到沙箱 localhost 埠限制，允許本機埠後原樣重跑通過。內容／全部模組語法與正式建置亦通過。來源編號最後一次修正僅改 elder GLB 的一個 JSON 字元及 Blender 自訂屬性，BIN、動畫與語義雜湊未變；修正後另重跑人物／資產／歷史角色整合測試。
