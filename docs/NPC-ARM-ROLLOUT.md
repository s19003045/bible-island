# 全島角色手臂與手部修正

## 2026-11-21 拇指朝向修正

使用者指出雙手看起來裝反。追查實際網格後確認，舊骨架中立姿勢的拇指位於內側，因此模型前方 +Z 對應手背，掌面應為 -Z。11/20 的姿勢層誤以 +Z 為掌面；手腕雖與前臂對齊，兩側拇指卻被轉向後方，指骨彎曲軸也跟著取反。

現已修正掌面映射、手腕座標基底及指骨彎曲方向。新回歸測試選取全部 28 份 GLB 的實際拇指表面頂點，驗證角色朝向 0、90、180 度時，放鬆雙手的拇指均朝角色前方。舊版第一份模型的左手測得後向約 49 mm，測試確實失敗；修正版全部通過。此檢查獨立於 runtime 的 palm 診斷值，避免實作與測試共用錯誤假設。提物右手及 v4 作者握姿不受此修正影響。

2026-11-20。適用全部 24 座島嶼及其章節，包含有名字的可交談人物與背景居民。

## 套用方式

- 28 種既有年代衣裝／體型使用 `human-arm-posture.js` 共用姿勢層。保留資產、身高、原本步行資料與碰撞控制器，依實際骨架校正自由手臂。
- 耶路撒冷三位生活精修角色繼續使用 v4 作者製作的手指姿勢、握持接點及腳底校正後的雙節手臂 IK，不疊加舊骨架修正。
- 空手時縮小肩部外張，保留捕捉動作的前後擺臂；掌心朝身側，手掌縱軸沿前臂，軸向旋轉分散到前臂。說話／互動漸進恢復原來手勢，手指稍微張開。
- 手指彎曲依每根指骨的實際方向與掌面求軸；左右手的小指側較彎，避免用同一軸硬轉造成手指側向散開。
- 提水者及抬約櫃祭司的右側握持骨鏈保留，僅修正空手側。原有握持幾何、道具及站位不變。
- 每個角色保存自己的局部關節平滑狀態。遠近景共用此流程；沒有新增共用行為計時器、隨機移動、服裝切換或資產下載。
- A/B 的「先前動作」明確停用此姿勢層，以免改變比較基準。

這次推廣的是手臂／手部與姿勢銜接修正。耶路撒冷的汲水、舀水、搬物工作站仍依該場景設定；不把這些工作行為無差別加入其他歷史場景。既有模型的幾何細節維持原樣，沒有宣稱所有角色已換成 v4 精修網格。

## 驗證

- `human-arm-posture.test.js` 載入全部 28 份實際 GLB，每份取樣 240 幀，涵蓋駐足、行走、交談、回到駐足及遠近景切換。檢查掌心朝向、腕部偏角、相鄰幀旋轉與控制器位置不變。
- 獨立驗證提水者／抬約櫃者的右肩、前臂與手腕局部四元數完全不變；v4 不套用舊骨架修正。
- 原有全島章節、衣裝幾何、平地／上下坡腳底及約櫃握持回歸測試保留。
- 瀏覽器檢視成人、長衣居民、兒童及提物者的手部與步態；視覺檢查是抽樣，不是所有時間的網格無穿透證明。
