# 耶路撒冷居民生活與手部精修

本輪範圍為耶路撒冷的住戶、提水居民、年長商販。其他島維持現有 v3 人物；經使用者檢視本試點後再決定推廣。三角色固定身分、衣裝及既有對話 ID，經文仍使用 YouVersion CSBT。

## 完成的行為與動畫

- 三份真實 GLB 分別包含 26、26、24 個動畫：左右起／收步、45／90／180 度轉身、上下階梯、聆聽及角色工作。視覺觀察器依碰撞控制器的實際距離／角度取樣，不能自行移動角色根節點。
- 住戶觀察、拿起、搬運、放妥同一件物品；提水者放罐、舀水、提罐、倒水；商販整理及展示器皿。六處工作站具備真實物件、水平工作面與碰撞，POI 共 28 點、61 個容量槽。
- 每人的工作進度、決策時鐘與種子保持獨立。交談凍結工作並在結束後接續；物品所有權在取／放完成後才轉移。
- 耶路撒冷預判迎面相遇、維持選邊、狹道讓行。避讓使用附近可達 POI，避讓路徑不超過 12 m，仍經掃掠碰撞。此新策略以 anticipation 開關限定試點，其他島保留既有選點行為。
- 上坡略減速，足部貼地後再解手臂鏈。手部 IK 保留肘彎曲平面與作者的掌心方向，不移動地面水罐來補償不可達目標。

## 手部與形體修正

空手休息時掌心朝大腿，手指自然彎曲；修正提罐手腕角度、手指包握與拇指支撐。取水時調整杯子位置及身體前傾，保留手臂實際長度。修補衣袖開口誤刪腋下衣面的問題。

CarrySmall 使用上半身骨骼白名單，保留步行腿部動作；白名單包含 propParcel 與 parcelGripL/R。漏掉接點會令手 IK 追逐 Walk 動畫的握點，造成指面偏位；本輪實際表面測試已涵蓋此回歸。道具及其子接點排除姿態慣性混合，工作暫停時不會緩慢漂移。有接觸約束的手掌／指骨亦排除舊自由手姿勢的慣性偏移，避免腕部 IK 對位後，指頭仍沿上一個動作穿入把手。自由手保留姿態過渡。

注意方向、眨眼及有限衣物次級動作維持個體化。工作中不加會破壞握持的軀幹搖晃；只有實際朗讀／語音啟動時張嘴，並未宣稱音素級嘴形同步。

## 使用入口

耶路撒冷主題面板／步行工具的「看看居民的一天」可以跟隨實際場景人物，查看當前工作。這不是另外複製的動畫展示。

「比較人物步態」保留舊 v3 與新 v4 的同一路線比較；新增「站姿與雙手」及「手部近看」，亦可觀察轉身、階梯、錯身、交談。

## 驗證與限制

- 全套回歸共 70 個測試檔、391 個案例：69 檔整合回歸加 dev-model-serving；初次失敗的資產 SHA、Fill 伸手距離、加利利避讓與 CPU 紋理載入檢查已修正並重跑相關案例。新增實際掌指表面測試亦通過。
- 新角色專用 6 項測試：真實動畫／骨骼、工作與對話中斷接點、平地與 ±0.2 坡面腳底、住戶／提水者各三種 30 秒路線的逐幀握持、樓梯上 CarrySmall 的實際掌指表面、提水者九個工作姿勢的真實封閉把手接觸。
- 50 人街區以最終 v4 控制器在 45.00 模擬秒內完成三角色各兩處工作站，過程不靠瞬移。
- 完整疊層的六個掌指表面抽樣，局部負向深度最大 0.442 mm，超過 0.5 mm 的抽樣頂點為零，拇指最近約 1.03 mm。這是變形後頂點對實際三角形的局部抽樣，不是所有三角形、所有時間的無穿透證明。
- 封閉把手使用實際三角形的 solid-angle winding 判斷內外；凹環表面的單一最近三角形法線可能誤判，不能單獨作為穿透證據。同時檢查拇指及至少一根手指距把手小於 4 mm，避免懸空握持。
- localhost 已檢視三角色及工作、新舊手部近景；第一人稱進入、切換居民跟隨正常，console 無 error。比較證據保存在 `.qa/jerusalem-life/resident-hands-final.png`、`carrier-hands-final.png`；原版本亦保留 before 截圖。
- `npm run check` 與 production build 通過。既有大型 bundle 提示仍存在；近景精細人物上限仍為 8，遠景保持相同衣裝。

動作採現代 CMU 參考與作者改編，並非古代動作捕捉。生活工作點及例行動作為教學推演，史料連結在介面中另行標示；模型仍是即時 3D 教學呈現，並非真人掃描。
