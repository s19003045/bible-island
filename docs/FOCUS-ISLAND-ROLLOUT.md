# 五座重點島：依序套用實作計畫

日期：2026-11-15 開始，2026-11-16 完成本機整合與總驗收。狀態：本輪已完成。群島全景與五座重點島已依序實作，包含會幕、所羅門聖殿、希律擴建後第二聖殿、出埃及三段及耶路撒冷整合。成果入口、93 項回歸、21 組場景／模式操作及待人工檢視的限制見 [五島總驗收](review/FIVE-ISLAND-ACCEPTANCE.md)。依據：[實作原則與技術總整理](IMPLEMENTATION-PRINCIPLES.md)。


## 1. 本輪要達成的結果

讓五座重點島都能以合理比例的第一人稱視角，探索符合當時脈絡的空間，遇見有目的活動的人物，觀察器物、閱讀或聆聽對話，並接回三種學習流程及 YouVersion CSBT 經文。

沿用現有詳細模型、15 位情境角色及學習內容，針對各島缺口補齊。本輪包含：場景層次調整、第一人稱行走、接地與避讓、符合職分的自主行為、近景觀察、空間環境音、人物配音與學習流程整合。另新增可獨立關閉的背景音樂，明示為現代創作。

第三人稱主角、AI 自由對話、動作捕捉、多人連線及帳號雲端儲存先不納入本輪。這些會另訂內容與技術計畫。

使用現有耶路撒冷作技術基準，第一個新增的完整成果選會幕。順序依空間與行為複雜度安排，不代表聖經故事時間順序。

| --- | --- | --- |
| 0 | 共用能力整理，隨會幕需求逐步進行 | 耶路撒冷原功能維持可用；行走、角色、器物及音訊開始由各島資料設定 |
| 1 | 摩西會幕（本輪已實作） | 從營地走近院幕，在合理界線內觀察器物、詢問工匠／祭司／家長，完成三模式流程 |
| 2 | 所羅門聖殿（本輪已實作） | 感受固定殿宇的量體與高差，繞看銅柱、銅海與牛座，與會幕對讀 |
| 3 | 希律擴建後第二聖殿（本輪已實作） | 沿設定的階梯、柱廊與公共探索區行走，遇見目的不同的居民與朝聖者，辨別時代與院界 |
| 4 | 出埃及（本輪已實作） | 在製磚、出發準備、渡海三段敘事切換探索，人物行為依段落改變，隊伍持續向前 |
| 5 | 耶路撒冷整合與五島總驗收（本輪已完成） | 原有街區、50 NPC 與任務接入共用架構，補齊聲音、模式及跨島比較的一致操作 |

每島都交付可操作的 dev server 檢視入口、變更摘要、來源／推定表與驗收結果。第一座會幕作為完整樣板，先確認方向，再把相同能力逐島套用。

## 3. 階段 0：讓能力可重用

目前需要處理的耶路撒冷專用設定，包括：`main.js` 的行走與配音入口、`world.js` 的人物查找及音訊更新、詳細場景的 walk model／NPC 建立、NPC 身分到職分的對應、音源座標，以及步行任務與進度儲存。

規劃將每島以下項目分開設定，並沿用既有控制器與狀態模型：

- 出生點、可行走表面、地面高度與法線、碰撞、樓梯代理、探索區域界線。
- POI、容量站位、角色職分與偏好、允許的活動區、行為模式及互動對象。
- 可近景觀察的器物、來源、讀經任務與模式對應。
- 聲源、地面腳步材質、配音索引、背景音樂與音量偏好。
- 按 island ID 分開的步行進度；遷移現有耶路撒冷紀錄，保留收藏及學習紀錄。

切島或切模式須取消舊尋路、釋出 POI 預約、停止舊音訊並釋放場景資源。先在會幕完成一條可玩的整合路線，再視實際重複需求抽取模組，避免先做龐大重寫。

## 4. 每島的場景與互動設計

### 1）摩西會幕：從營地理解空間界線

- **場景：** 補強營地入口、帳棚、織作區、搬運路線與院幕的前中遠景，核對人物、帷幕、繩索與器物比例。
- **探索路線：** 營地 → 工匠觀察點 → 院幕入口與外院觀察區。實際可進入範圍先依經文與角色設定核對；聖所／至聖所採有標示的教學剖面或近景視圖。
- **NPC：** 織作工匠在工位與材料處活動；家長在營地生活區停留；祭司在已設計的服事區活動。各自有 POI、工作／觀望／交談與獨立節奏。
- **器物與問題：** 觀察織物、板架接合與洗濯盆，辨別銅壇／香壇；聖物提供近景解說，不套用日常器皿「拿在手中」的文案。
- **聲音：** 風、織物、腳步與工作聲；角色台詞配音。背景音樂獨立控制，不當作古代實際曲調。
- **驗收焦點：** 自由行走與教學剖面界線清楚；人物不穿帷幕、帳棚或器物；觀察後能回到原本的親子／一般／研讀流程。

### 2）所羅門聖殿：固定建築、銅器與尺度比較

- **場景：** 加強院落、坡地、周圍聚落與殿宇量體關係，檢查側屋、銅柱、銅海與人物尺度。
- **探索路線：** 院中觀察區 → 銅柱 → 銅海周圍；以剖面理解內部。通道、高差與進入界線各自建模，不讓觀察模式等同自由穿越內殿。
- **NPC：** 銅作工匠在解說與器物觀察點活動，訪客在可用院區移動，歌者在設定區域停留。建殿、獻殿敘事分開標示，避免暗示不同階段同時發生。
- **器物與問題：** 近景看柱頂構件及銅海承托方向；比較會幕洗濯盆、可搬會幕與固定殿宇。每個復原細節附依據或限制。
- **聲音：** 石地腳步、院落環境與情境配音。若加入歌者或樂器聲，標示為現代聲音設計，不能聲稱復原獻殿原曲。
- **驗收焦點：** 全程上下高差不頓挫；沒有把第一聖殿模型寫成已出土測繪；跨島比較可返回原任務。

### 3）希律擴建後第二聖殿：階梯、人流與院界

- **場景：** 補強階梯、平台、柱廊的空間深度及遠近人群；維持成人尺度，不靠縮小人物誇大建築。
- **探索路線：** 朝聖階梯 → 已設定的公共觀察區 → 柱廊。先核對年代、院界與可進入條件，再決定探索範圍；內部使用教學視圖。
- **NPC：** 朝聖者在目的地與同行節點間移動，聆聽者在柱廊停留，石作角色在指定解說區活動。人流保留個體速度、站位及決策差異；狹處可停讓。
- **器物與問題：** 觀察石材構件與院界，辨別第一聖殿、歸回重建及希律擴建。不同福音書段落不合併成同一天。
- **聲音：** 腳步、分散人聲與柱廊環境；聲音和配音不搶讀經注意力。
- **驗收焦點：** 樓梯連續上下、人群與玩家防重疊、無隔牆交談；文獻差異與復原年代可查。

### 4）出埃及：三段故事、不同活動規則

- **場景：** 保留製磚、預備出發、渡海三段，以章節選擇及明確轉場連接；不把並置佈景做成一條可量測的真實旅路。
- **探索路線：** 三個獨立探索區各有出生點與安全邊界。玩家切換段落時交代敘事先後；不設定虛構的確定法老、日期或渡海座標。
- **NPC：** 製磚區以材料、工作與休息 POI 驅動；住家以預備及搬運活動為主；渡海隊伍依各人速度、間距與進度單向行進，不折返、不任意離隊。微交談僅在合適狀態與區域啟用。
- **器物與問題：** 草料、泥磚與磚模，門框與行囊，隊伍腳下乾地；勞役場景著重理解處境，不設計成娛樂化的生產競分。
- **聲音：** 三段分別配置工作、住家及風水環境，轉場時切換並淡出舊聲源；配樂不淹沒台詞。
- **驗收焦點：** 敘事次序清楚，隊伍長時間不掉頭、不穿透，畫面距離與人物數量不被當作史實測量。

### 5）耶路撒冷：保留成熟功能並整合

- **場景：** 針對主街、巷弄、院落與遠景補足遮蔽、材質及可辨識的空間層次；範圍仍依有界公共街區設計。
- **既有能力：** 保留 50 NPC、24 POI、57 站位、石階控制、陶器／石器近景、四階段小旅程與原有進度。
- **整合：** 換用共用設定入口，統一五島的行走、聲音、近景與返回學習流程；補上獨立音樂控制及配音檢查。
- **驗收焦點：** 舊旅程與配音不回歸失效；切換五島後沒有殘留人群預約、音訊或操作狀態，收藏／札記／模式進度不遺失。

## 5. 五島共用的品質底線

| 項目 | 本輪規格 |
| --- | --- |

| NPC | 每人獨立 seed／PRNG／狀態計時；速度 0.85–1.15 倍；POI 預約及容量；平滑轉向；分離與硬性防穿透；禁止 Random Walk 與共用決策計時器 |

| 經文 | 全部使用 YouVersion CSBT 312，保留原有多段與跨章參照；考古來源仍連回原資料 |

| 效能 | 不要求每島塞入同樣 NPC 數量；依場景密度與實測設定人數及細節預算，保持手機與安靜／減少動態選項可用 |

## 6. 每島的實作節奏與驗收關卡

每島按照以下次序完成，場景內容變更時同步維護史料與測試：

1. **空間與史料稿：** 閱讀目標、探索區域圖、人物活動區、器物清單、來源與推定、音訊腳本。
2. **可走動版本：** 比例與景深、出生點、碰撞、坡面、樓梯、點地尋路及返回全景。
3. **活的場景：** NPC 目的地與工作動作、容量預約、避讓、短暫社交、玩家對話停步與恢復。
4. **完整學習體驗：** 器物近景、三模式任務、CSBT、情境配音、環境聲及選用配樂。
5. **交付檢視：** 自動檢查與針對性瀏覽器試玩，提供「本次完成／仍待調整／來源取捨」，第一座會幕作為後續各島驗收樣板。

驗收需涵蓋：NPC 容量與長時間防穿透、合法／超高階與陡坡、上下階及不同幀率、所有模式完成路徑、讀音與配音對齊、音訊取消、舊紀錄遷移、反覆切島、鍵盤與觸控。既有 65 項加上群島全景 6 項、第二聖殿 6 項、出埃及 8 項、共用音訊 3 項、耶路撒冷整合 4 項及窄道退讓 1 項，共 93 項全數通過；另完成瀏覽器 21 組場景／模式操作。這些結果不等同獨立歷史審稿、完整真人聽驗或實體手機認證，限制見總驗收表。

本輪先提供本機 dev server 檢視；Sites 發佈作為功能驗收後的獨立交付。各島功能完成與實際網站上線須分別記錄。
