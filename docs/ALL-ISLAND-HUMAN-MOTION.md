# 真人參考步態、聲景與自由移動：全島延伸

2026-11-17。本輪將耶路撒冷 v44 試點的 motionVersion 3 延伸至全部 24 島；音樂、音效、快跑及跳躍沿用全島共用系統。最終驗證及發佈結果記於 `DEPLOYMENTS.md`。

## 人物與歷史衣裝

- 新增 28 份獨立 GLB：`public/models/human-rollout/`；各有 `assets/blender/human-rollout/<base>.blend` 可編輯來源、原始 GLB 雜湊、量測及動作報告。原 28 個 GLB、共用 Blender 來源及三個耶路撒冷試點檔保留。
- `resident-appearance.js` 先選原有時代／角色／身高，再映射到同一衣裝的 `human-<base>`。兒童、長衣、赤足工人、一般祭司、歸回長者與提水者使用自身比例與配件；不將耶路撒冷衣服套用到其他時代。
- 以 CMU 07_01 成人步行、07_04 成人慢走為基礎，120 Hz 重定向至原角色；兒童、承重、長者及長衣步態為作者改編，並非捕捉那些身分或古代人物。原 ASF／AMC、BVH、授權與來源存檔沿用 `assets/blender/jerusalem-pilot/reference/`。
- 實際蒙皮包含多節脊柱、自由側鎖骨、腳趾、自由手指、眼睛、眼皮及衣料輔助骨。保留可見幾何及表面顏色，修正衣料內皮膚的既有穿袖缺口；長衣依小腿形狀調整下擺跟隨並檢查包覆。
- 提水者右手與水罐維持同一握持關係。約旦河持竿者保留原右手握竿與左手自然下垂，依經文場景站立，不加入閒逛，也不虛構另一隻握竿手。

## 控制器、步態及效能

- 每個 NPC 原有 POI 權重／容量、獨立 seed、0.85–1.15 速度差、錯開的決策計時器、分離／避讓與偶發短談維持。沒有群體共用決策時鐘或 Random Walk。
- `human-navigation.js` 沿碰撞確認的保留路線前看，轉彎先減速並限制身體角速度。出埃及／約旦河隊伍也使用平滑轉向，維持向前進度與人群間距。
- 各衣裝的基礎速度上限取自身實測循環距離／秒長，再乘個體速度係數；較短的長衣步幅不會被要求追上一般居民的固定速度。
- `human-locomotion.js` 僅觀察控制器距離／朝向，處理起步、距離對應步態、收步、轉身及對話中斷。`human-performance.js` 使用獨立視覺隨機，處理注意方向、眨眼、姿態及有界衣物反應，不消耗行為 PRNG 或移動碰撞根節點。
- 完整變形腳掌與腳趾分辨腳跟／全掌／腳尖支撐，使用雙腿 IK 貼合地面。近景完整處理最多八人；遠景保留同一服裝、骨架與配件，降低取樣率與索引量，90 m 外停止繪製。
- `scene-cache.js` 只保留最近三個實體場景，切換更多島／章節時釋放舊場景及人物實例。閱讀、札記及探索紀錄仍由獨立的持久化資料管理。

## 聲音、移動與比較入口

- 既有五首原創循環配樂按章節選曲，土／石／木腳步與落地、起跳及器物音效在全部島共用；環境、動作、語音、音樂分開調整。點「開啟聲音」後播放；安靜探索、隱藏頁面靜音、對話降低背景聲維持。
- 新增附近 NPC 空間腳步。每人依實際腳部「擺動→支撐」接觸切換及實際行進距離發聲；遠方、停步、交談、靜音及換場不補播過時腳步。按距離限制同幀聲音數量。
- 每島提供 Shift／畫面快跑，以及 Space／畫面跳躍；步行 2.2 m/s、快跑 4.5 m/s、跳高約 0.6 m。共用跨階、坡限、地面吸附、空中碰撞與平滑鏡頭。跳躍不開放未建模背景、屋頂或古代身分限制區域。
- 自動前往會保留真正目標的最後一段安全路線。目標格點暫時被人佔用時，依碰撞等待／重新規劃，不把鄰近空格當作已抵達；同席場景的擁擠動線及步行／快跑模式均有實際回歸。
- 全島皆有「比較人物步態」，只列出該場景實際使用的人物衣裝；以相同控制器、POI 路線與速度，觀察原 v2 與 v3 的直行、轉角、收步折返、階梯、錯身與交談。不改閱讀進度。

## 重建與驗證

先執行 `scripts/blender/human-motion-rollout.py` 匯出實際素材，再執行 `node scripts/prepare-human-rollout.mjs`。後者只接受完整 28 份報告及一致的 GLB SHA，產生 `src/human-rollout-assets.js`、runtime JSON，並合併全站資產報告；原資產條目保留。

`tests/human-rollout.test.js` 直接讀取 28 個新 GLB，比較原有表面座標／顏色、確認原檔及可編輯來源雜湊、實際骨架權重與動畫秒長；以連續 141 幀檢查平地及雙向坡面完整腳掌／腳趾，並驗證持竿者在呼吸／注意動畫中仍接觸實際竿位。另逐島／逐章確認服裝映射、個人控制器與比較選項。

聲音檢查涵蓋 117 個實際章節／階段的選曲及動作音路由；移動測試逐島／逐章檢查起跳、落地、快跑及公共區域邊界。這些有限取樣不等於真人全曲聽驗、完整布料模擬、寫實臉部或所有裝置的效能保證。

最終回歸共 63 個測試檔、363 項通過（62 檔／362 項完整回歸，加上原樣允許 localhost 後的 1 項伺服器測試）；內容、所有模組語法及正式建置通過。首輪找出兩個仍使用舊資產 ID／路徑的測試，以及擁擠場景自動前往停在鄰近格點的實際問題；修正後再次跑完整回歸，未降低碰撞、間距或抵達標準。

瀏覽器已實測保羅的跨章聲景、曠野快跑／起跳與四類音量、全島比較入口、會幕一般祭司的階梯／側面比較、西奈居民的情境對話，以及跨越三個場景後重新進入與閱讀紀錄保留。實際模型資料為 motionVersion 3，交談時控制器為 held、骨架為 Talk，console error／warning 為空。素材的獨立來源及代表畫面審查另見 `assets/blender/human-rollout/review-final.md`。
