# 人物、聲景與自由移動：三階段實作

2026-11-17。三階段已整合；程式碼使用 develop，發佈沿用既有 Sites 與分享範圍。

## 第一階段：耶路撒冷完整示範

- 新增 Walk、StartWalk、StopWalk、TurnLeft、TurnRight，保留 Idle、LookAround、Interact、Talk。包含骨盆與肩膀反向轉動、屈膝、腳跟到腳尖過渡，成人、孩童、持物者有各自尺寸／步幅。
- 碰撞控制器唯一負責角色位置；步態依實際行進距離取樣，避免播放速度與位移不合。足部接觸使用實際腳部全部剛性頂點，曲面赤腳不能只取 rest pose 最低一圈；雙腿 IK 與骨盆補償處理坡面，LOD 切換保留步態相位。
- 保留各人 seed、速度係數 0.85–1.15、錯開的 POI 計時器、容量預約、分離與避讓、20% 偶發短談。轉彎先減速再平滑轉向；重選失敗路線時仍記得上次真正駐足的 POI，不立即返回原地。
- 「比較人物步態」實際載入先前與新版 GLB，在相同 NPC 路徑／速度下比較。可切換居民、提水者、工作者、孩童，暫停／重播、正面／側面、單人／並排；不改閱讀進度。
- 原創城鎮循環配樂與物理動作音效；環境、動作、語音、音樂四個音量。對話壓低背景聲，切場淡出，保留安靜入口與使用者啟動，隱藏頁面時靜音。
- 步行 2.2 m/s、快跑 4.5 m/s；Shift 或畫面切換，具有加減速與斜向速度正規化。已觀察教具可快速返回，只移動位置。
- Space／畫面按鈕跳躍約 0.6 m，重力 10.8 m/s²、120 ms 輸入緩衝、100 ms 離地寬容；連續頂碰撞／落地，不在空中吸附。新增明示原創教學用途的公共矮牆院落，可跳入、跳出。

## 第二階段：階梯、坡地與邊界

希律公共大階梯與西奈三段坡地採同一控制器：保留 0.35 m 自動跨階、45° 坡限、向下吸附與視覺 Y 平滑，上坡速度約 0.8 倍。跳躍仍服從公共範圍、高牆與地形坡限；不解除內院或未建模區域的限制。

30／60／120 FPS 的實際場景模型測試包含快跑抵達、階梯狀態、地面法線、跳躍落地、鏡頭高度連續性。可見慢幀以小步積分，在 1／4／10 FPS 測試保留地面行進距離；長時間停用不重播全部時間。骨架與 GPU instance 姿態每個畫面只提交一次，避免每一物理子步重做視覺工作。

## 第三階段：全部 24 島

- 28 種人物均為 motionVersion 2，28×9 個動作。原有 mesh／材質／蒙皮與原四種手勢保留；五種赤腳角色使用量測後的 5.6–5.7 mm 新步態骨盆補償與 120 Hz 烘焙，其餘 60 Hz。來源為 assets/blender/bible-assets.blend；motion-rollout.json 與生成腳本記錄可重建的參數。
- 五首原創配樂：城鎮 96 s、曠野 320/3 s、湖岸 96 s、建造 100 s、莊嚴 96 s。依章節選曲、OGG／MP3 後備，使用真正循環與有限交叉淡化，只保留一首解碼快取；不常駐五首 PCM。40 種動作音效涵蓋土／石／木腳步與落地、起跳、陶／木／石互動。
- 原有 75 份角色配音與字幕 cue 保留。場景／音樂切換會取消過時語音與動作音效，延遲下載的腳步不會事後補播。
- 全部公共探索區提供快跑、跳躍、已觀察教具快速前往。過河隊伍與約旦河複合 NPC 系統補上包含高度的空中避讓；古代身分限制與現代教學觀察視角仍分開說明。
- 所有經文連結維持 YouVersion CSBT；閱讀模式、學習完成度、札記與不同島／章節的紀錄分開保存。

## 驗收與證據

最終回歸：58 個測試檔、338 項通過、0 失敗。涵蓋 24 島各分章的公共範圍與起跳／落地、NPC／POI／對話、三種閱讀模式與學習隔離、所有 101 個正式 GLB 的 hash／尺寸／預算、音檔 hash／換場／音量。獨立完整腳部測試對 28 種人物、三種坡面、每種 181 個連續姿態檢查完整腳部接觸，包含初始腳跟著地。

素材來源與有限取樣 QA：assets/blender/motion-upgrade-report.json、motion-all-upgrade-report.json；public/audio/original/provenance.json、moods-provenance.json。原四種手勢按秒取樣，不能因 Euler→quaternion 或 60／120 FPS 轉換而改變秒長。來源合併保留 101 個非空場景、28 人及羊；三份模型的 Blender importer 退化面清理差異另有紀錄，原新 GLB 的實際 indices／attributes 相同。

實際瀏覽器已操作耶路撒冷院落跳入／跳出、快跑抵達居民、語音提問、新舊四種角色比較與暫停／重播。已觀察水罐的快速返回實測會改變位置，任務仍為 2/4、閱讀完成度仍為 0/3。390×844 窄螢幕已檢查行走／快跑／跳躍及比較介面。完整測試輸出與瀏覽器截圖保留於忽略版控的 .qa/。

上述不是獨立歷史專家簽核、真人全曲聽驗或實體手機效能保證。素材是現代原創教學重建，不宣稱歷史人物影像、古代音樂或考古定址；跳躍也不保證每個背景屋頂都可探索。
