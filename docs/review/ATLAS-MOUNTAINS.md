# 群島全景：山谷水域、樹林與流雲

2026-11-16。延續既有群島閱讀主線；參考 [政策島](https://puma.taipei/heart-island) 的周圍山坡與中央水域構圖，獨立製作地形與程式，沒有複製其素材。部署結果另見 [Sites 紀錄](../DEPLOYMENTS.md)。

## 本次變更

- 群島改由有起伏的連續山地環抱中央水域，包含低處通口、不同高度山脊、岸坡、樹林及近岸淺色過渡。山地與湖岸是閱讀情境設計，不是聖經地理測繪。
- 周圍山地由約 20,817 個頂點形成連續曲面，640 株樹以兩個 InstancedMesh 批次繪製；保留共享材質／幾何。背景由光照與既有遠霧建立層次。
- 22 組白雲沿山區緩慢移動，各有不同相位、速度、大小和海拔。高度依實際山面加安全間距計算，避免藏入地形。使用可重現的程序透明貼圖與朝向相機的平面，沒有新增遠端圖片或雲端執行服務。
- 暫停／減少動態沿用場景時間；停止時雲與水面不繼續前進。日夜切換同步雲色與亮度。
- 全景預設拉開視野，閱讀路線卡先收合；選擇單一路線時仍聚焦相應島嶼。島 ID、各島詳細場景、收藏、閱讀足跡和模式紀錄不變。

## 驗證

新增三項地形測試：各方向山地與低處通口、全部島嶼及岸緣保留水面空間、不同螢幕比例／各閱讀路線鏡頭的地形遮擋、白雲高度／移動／朝向／固定時間暫停／日夜，以及共享資源釋放。測試曾指出前景山坡遮住保羅與初代教會島，已調整預設鏡頭並重驗通過。

全部 96 項測試、24 島／74 探索點內容檢查、語法檢查、正式建置、單檔試閱與 `git diff --check` 通過。Three.js 共享檔仍約 530 KB，為既有建置提醒。

瀏覽器確認桌機山景與白雲、閱讀路線切換、日夜及暫停。390 × 844 的 viewport／scrollWidth 同為 390；閱讀路線選單與收合卡皆在畫面內。手機尺寸的日／夜畫面及桌機畫面分別保存在 `.qa/mountains-mobile.png`、`.qa/mountains-mobile-night.png`、`.qa/mountains-desktop.png`；驗收頁未記錄 console error。開啟或重新編譯 WebGL 畫面時曾有瀏覽器觀察逾時，重讀同一分頁後成功，沒有重啟工作取代未確認的結果。
