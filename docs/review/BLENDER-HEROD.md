# 希律聖殿三件 Blender 教具

2026-11-16。十四項既有觀察物已有十一項 Blender 替換；出埃及三件、人物寫實化與十九座詳細島嶼仍待完成。

## 製作內容與界線

`scripts/blender/herod-props.py` 由共用 Blender 4.5.16 LTS 流程執行，三件皆保存可編輯場景與本機 GLB，工作桌及旋轉近景共用相同網格。來源與比例表見 [素材說明](../../assets/blender/README.md)。

- 石材教具高 0.40 m；真實網格呈現低於中央面的凹邊、細短加工痕、石塊厚度及接縫，右側石塊可分開／還原。[IAA 發掘報告](https://hadashot.iaa.org.il/Report_Detail_Eng.aspx?id=1738&mag_id=118&print=all)提供邊帶加工的背景，模型不是原石掃描，也不將刀痕及教具尺寸當作發掘測量。
- 院界教具高 0.692 m，實際十四階、低欄、內側高牆與門洞形成層次。十四階對照[《猶太戰記》5.5.2](https://sacred-texts.com/book/the-works-of-flavius-josephus/book-v)，全體不採統一縮尺；欄形、位置與組裝屬示意，不擬造碑文。拆開低欄僅為教具觀察，不改變內院不可步行的限制。
- 柱式教具高 0.76 m，含短柱身、實際有厚度的兩層葉飾、角渦卷與承托板。首輪檢視發現葉片部分藏入柱體，已沿柱體外輪廓修正附著；渦卷亦移到柱頭角部。參照[《猶太古史》15.11.5](https://sacred-texts.com/book/the-works-of-flavius-josephus/book-xv)所述南側王家柱廊的科林斯式，使用者說明明確指出不能由此認定約翰所述所羅門廊柱式。葉片數量、形制、表面及比例為教學選擇。

三件的使用者說明直接包含史料界線；石材與柱式另補研究／古代文獻入口。經文仍連 YouVersion CSBT，沒有改寫人物對話或已錄製語音。其他場景的柱廊建築並未因這件教具而全數改為此柱式。

## 驗證

全套 **115 項測試**通過，包含 51 位希律 NPC 的獨立 POI、容量、避讓與社交行為、28 級大階梯上下行、語音與學習流程回歸。24 主題／74 探索點、語法、正式建置與離線試閱均通過。

新增四項直接讀取實際 GLB 的驗證：射線量出凹邊低於中央面；旋轉後右石拆合、固定左石及無偏移還原；逐階射線核對十四個上行表面、低欄與牆分離；兩層葉片幾何、總高與承托頂面；三件實際場景替換、遮擋物更新與合法接近路線。拆開院界教具並隱藏屋頂後，內院及陳列桌仍不可通行；GLB 不可用時，備用模型仍保留拆合控制。

十二場景 `.blend` 已再次用 Blender 開啟，確認十六個葉片群組、右石／院界拆合階層及原有五種人物動作。石材 3,556 三角形／165,524 bytes；院界 8,460／814,876；柱頭 20,328／487,136。檔案 SHA256 及現有十二份 GLB 由 [建置報告](../../assets/blender/build-report.json)記錄；不包含外部貼圖或執行期模型服務。
