# 五座歷史場景：第一輪試閱

這一輪只重做摩西會幕、所羅門聖殿、新約時期聖殿、出埃及、新約耶路撒冷的詳細場景。其餘 19 座維持原有模型；群島總覽繼續作為主題入口。試閱完成後，再依使用者回饋決定如何擴展。

## 這次的改變

| 場景 | 比例與建築 | 新增的環境層次 |
| --- | --- | --- |
| 摩西會幕 | 依經文院幕尺度、板架、銀座、銅祭壇、七燈、十二陳設餅、幔子及約櫃；屋頂改為多層覆蓋物 | 院外營地、織物帳棚、拉繩、行走者、器皿與曠野地形 |
| 所羅門聖殿 | 殿身、三層側屋、銅柱、柱頂裝飾、十二牛承托的銅海、銅壇及木作金飾內部 | 院落、周圍家屋、坡地與橄欖樹；外牆與內部材質分開 |
| 新約時期聖殿 | 殿宇立面、內部空間、分層院落、欄界、祭壇、柱廊及高台 | 步行者、朝聖階梯及潔淨池類型示意；聖所不放約櫃 |
| 出埃及 | 正常比例的步行者、兒童、行囊、泥磚工藝、住家與渡海通道 | 分段並置製磚聚落、逾越節住家、營地與海面；畫面標明不是連續地理 |
| 新約耶路撒冷 | 平屋頂家屋、內院、外梯、院牆、門窗、儲水設施與器皿 | 多層住區、巷弄、階梯主街、城門截段、谷地與東側山坡方向 |

新詳細場景以公尺為單位；成人參照身高為 1.70 m，頭部約 0.225 m。各場景共用同一人物尺度。兒童縮小身高，沒有放大頭部。

新增「場景全景」「人物尺度」「俯視配置」三個視角。選取這五座時，主題清單收進抽屜，讓 3D 畫面有較大寬度。器物探索點仍可從側欄使用，室內探索點會自動開啟剖面。

## 史料與取捨

- 古代「肘」使用 **0.45 m** 作為統一換算約定；這不是認定所有時代的肘長相同或已有定論。
- 會幕以出埃及記為主；帳幕寬度、覆蓋物細部、洗濯盆形狀、器物間距與營地外觀含有復原假設。
- 第一聖殿主要依列王紀上，並對讀歷代志。前廊高度、外院及周圍城市不宣稱精確。側屋採三層、逐層增加的寬度；殿壁厚度和外部量體仍屬建築復原。
- 新約聖殿呈現核心院區的教學截景，外圈平台不是完整聖殿山測繪。約瑟夫斯、《米示拿》與考古資料不應直接混成單一年代的確定圖。以色列博物館城市模型的年代為西元 66 年，不能直接等同耶穌活動年代。
- 出埃及不指定法老、日期、路線或渡海位置。水牆高度和隊伍人數為敘事表現；三個探索點不是同時發生，也不是彼此相鄰的地理位置。
- 耶路撒冷是第一世紀街區的類型復原，並非逐戶考古復原或全城測繪。谷地與山坡間距經構圖取捨，沒有放入後世圓頂或現代舊城牆。

每座的「查看尺度與復原取捨」列出該場景的文字依據、資料連結與不確定部分。這是依公開資料製作的開發試閱版，尚未經聖經歷史學者獨立審稿。人物與地景仍是程序建模，沒有宣稱達到真人掃描或電影級擬真。

## 如何試閱

1. 執行 `npm run dev`，從左側清單選取標有「新版」的五座主題。
2. 每座先比較全景與人物尺度，再看俯視配置及室內剖面。
3. 開啟「查看尺度與復原取捨」，區分有文字依據的尺度與推定外形。
4. 這輪優先評估：成人是否仍覺得過度卡通、人物與建築是否合理、視野及層次是否充足，以及史料取捨是否可接受。

也可執行 `npm run review:bundle` 產生 `.qa/five-islands-review.html`。這是單一 HTML，下載或複製後用支援 WebGL 的桌面瀏覽器開啟即可；3D 程式、樣式及程序材質均內含，無須本機伺服器或 CDN。經文與研究來源連結仍需網路。收藏與探索紀錄使用目前瀏覽器可用的本機儲存。
