# Blender 首批整合驗收

2026-11-16。本輪是素材管線與耶路撒冷初步替換，整個 Goal 仍持續；不視為五島美術全部完成，也未開始十九座詳細島升級。

## 實際交付

官方 Blender 4.5.16 LTS 已下載、SHA256 校驗並在背景執行。原創製作腳本匯出三份 GLB，保存一份含三個素材場景、骨架權重與動作的 `.blend`，並已成功重新開啟。尺寸、三角形數、動畫、位元組數與雜湊記錄於 [建置報告](../../assets/blender/build-report.json)。來源、服裝年代與器物形制的取捨見 [素材說明](../../assets/blender/README.md)。

耶路撒冷一般成人居民近距離使用五種骨架動作；每位有自己的 skeleton、mixer 及原 NPC 時間。動畫從 Walk／Idle／LookAround／Interact／Talk 平滑混合，沒有另設共用 NPC 行為計時器。最多八位細節人物，使用距離滯後減少反覆切換；遠處維持原批次輪廓，搬水居民與孩童保留相應舊造型。

院落陶罐與石器在場景／旋轉近景共用本機 GLB。讀取未完成或失敗時保留原有模型。取消載入後不再替換已關閉場景；替換會釋放原模型幾何與材質，實例共用的 GLB 資源在主程式卸載時才統一釋放。骨架點選有保守的姿勢邊界，場景仍以實際身體網格判定。

## 驗證

- 完整 100 項測試、24 主題／74 探索點檢查、語法、正式建置與離線試閱封裝通過。
- 四項新增測試直接讀取真正 GLB：檔案／雜湊與尺度、骨架時鐘隔離／動畫／零時間暫停／移動後點選、近距離八位上限與排除條件、器物替換與非同步取消／資源生命週期。
- Blender 首次渲染指出曲面環架反向造成小腿扭轉，已改成連續傳遞局部截面方向；並修正腳踝接合、成人眼部尺寸和衣袖輪廓。匯出曾遺漏頂點顏色，已接入 PBR node tree 並由測試核對匯出屬性。
- 本機瀏覽器已開啟耶路撒冷，選住戶交談；畫面顯示新成人模型及兩件器皿，沒有 console error／warning。截圖 `.qa/blender-resident-scene.png`。已確認安靜探索與研讀模式的器物沿路前往入口；完整器皿近景操作另行補上結果。
- Sites 正式頁重新載入後，DOM 引用新 `index-CzR6x_Vm.js`，選住戶可見實際 Blender 模型及原有對話；截圖 `.qa/blender-sites-published.png`，console error／warning 為空。最初只改 hash 仍持有前版程式，已以實際重新載入核對，而非把平台成功推定為畫面驗收。
- 單檔試閱約 26,357 KiB，內含既有十八份 MP3 及三份本機 GLB；沒有增加執行期雲端模型服務。Three 共用 chunk 約 586 KB，建置仍提示超過 500 KB，未宣稱任何固定 FPS。

## 尚待完成

人物仍有風格化外觀，需要更成熟的臉部／衣料材質、衣袖與手部接合、步態足底接觸及多樣人物。搬水持物、孩童、婦女、祭司、舊約各時期服裝與其他十二件器物仍待製作；本輪沒有通過獨立美術／歷史專家或實體手機驗收。Sites 的實際發佈結果以 [部署紀錄](../DEPLOYMENTS.md) 為準，不以本機通過推定已上線。
