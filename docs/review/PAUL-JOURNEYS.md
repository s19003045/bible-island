# 保羅宣教之旅：第八座詳細島

2026-11-16。本島選三次旅程各一個代表城市：帕弗港口、腓立比城外河邊、以弗所工坊。不是三次行程的所有城市模型，也不是可從帕弗走路到腓立比的連續地圖。其餘十六島仍待升級，完整 Goal 保持進行。

## 經文、分期與重建選擇

- 第一次旅程：對讀 [徒 13–14](https://www.bible.com/zh-TW/bible/312/ACT.13.CSBT)，區分安提阿的差派、西流基與撒拉米的海路、經島上各地到帕弗，再開船往別加。船的圖樣、貨物、港口與街區為類型選擇，不是保羅座船或住址的考古認定。沒有搬入現在帕弗的中世紀城堡；[UNESCO 遺址介紹](https://whc.unesco.org/en/list/79) 的不同時期不能整組移回第一世紀。
- 第二次旅程：[徒 16:11–15、40](https://www.bible.com/zh-TW/bible/312/ACT.16.11-15.CSBT) 分清尼亞波利與腓立比、城外河邊與家庭接待。紫色布商身分有文字依據；染料、工坊、河段、家屋與這位無名布商的服裝沒有確定坐標。[UNESCO 分期](https://whc.unesco.org/en/decisions/6804) 用來區分羅馬城與後來的基督教大教堂，本場景沒有後期教堂。
- 第三次旅程：[徒 19](https://www.bible.com/zh-TW/bible/312/ACT.19.CSBT) 連起教導、工匠生計、騷動與城市秩序，沒有讓保羅站進劇場向騷動群眾講道。長老告別另在 [米利都，徒 20:16–38](https://www.bible.com/zh-TW/bible/312/ACT.20.16-38.CSBT)。[奧地利考古研究所劇場分期](https://www.oeaw.ac.at/en/oeai/media/press-releases/baugeschichte-des-theaters-von-ephesos-rekonstruiert-2) 指出後來的擴建，本章用較早類型、沒有巨大晚期拱廊；排除晚期形制不代表本模型的尺寸與席次已完全實測。

三章有各次行程摘要，並把 [徒 27–28 押解赴羅馬](https://www.bible.com/zh-TW/bible/312/ACT.27.CSBT) 列作另一趟閱讀入口。摘要省略部分停留與回程，不當成精確航圖；保留原探索點 ID，使收藏／既有閱讀紀錄相容。書信仍透過相關島連起，不為各書信指定一致的寫作地點定論。

## 場景與角色

港口有開放海面、商船、貨物、碼頭、上行街道與港城背景；腓立比有城外道路、河邊、樹蔭、布料與城門背景；以弗所有工坊、柱廊外通道、早期劇場類型和後方地勢。近處地面另加密，與物理樓層一致。每章一位可交談綜合角色及十四位居民，八組 POI／24 個容量位置；保留個別 seed、計時、速度、避讓、平滑轉向與偶發交談。

合法步行面及工位／遮蔭桌／長椅碰撞分開定義，海面和河道不當成可走地面。教學碼頭有自己的物理地面；既有控制器處理坡度、接地及視覺平滑。各城的環境音效使用獨立位置與地面音色，仍可全程安靜探索。
