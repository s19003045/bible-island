無名導讀角色預定日常文書協作者、行旅交付協助者、聚會接待／聆聽協助者；不自稱保羅、特提烏斯、特其庫斯或原始收信人。三模式分別沿文本、先觀察再問答、核對經文／研究／補足；札記與其他島隔離。完整派生24cue覆核後才各一次固定聲音生成。

奴役、捆鎖與不平等保留為有脈絡的閱讀，不把奧尼斯莫改成可買賣／交付人物，不假定必偷竊、逃跑或已獲法律釋奴；不要求兒童扮奴僕或以服從傷害通關。腓利門書另開完整對讀，不認定同袋同日。菲比的推薦與服事保留，攜羅馬書／朗讀全卷仍分作推論，不能由現代場景確證。
