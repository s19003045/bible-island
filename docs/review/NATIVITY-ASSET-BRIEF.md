# 第十八島：三件原創教具的有界設計稿

2026-11-16，根代理依[研究起點](NATIVITY-RESEARCH-START.md)及[施工決定](NATIVITY-IMPLEMENTATION-PLAN.md)提出。這份稿件先供史料界線與幾何可行性覆核，**尚未授權製模、修改正式來源、註冊app或生成配音**。不是伯利恆原屋、拿撒勒原宅、耶穌原工具的復原認證。

## 共同取捨

三件的外形、尺寸與分件均由現代教學目的選定；不使用未曾目視的Pompei飼槽照片、未讀到的IAA平面或未目視的館藏工具照片來聲稱精確臨摹。模型在公共觀察區出現，場景和近景應沿用同一件正式GLB及公尺尺度，另以UI區分經文描述、研究比較與原創補足。不得做假古字、認證人物肖像、具名家庭所有權或古代標準化尺寸。

本輪不製作嬰孩、十二歲耶穌、約瑟或瑪麗亞肖像。空槽不能被說成故事中孩子不存在，只表示教具只呈現一件物件；人物與安放的敘事由經文及導讀交代。不得用縮小成人、頭部玩偶或可拋接包裹替代嬰孩。三件也不把牧人、博士、聖殿教師及成年返鄉聽眾放在同一間屋子。

全部幾何須有真底、真厚、封閉外殼與清楚承托。底面Y=0；Blender使用Z向上，glTF使用Y向上。每件預算不超過30,000三角形／1.6MB；小尺度細節依近景可辨識度決定，不以高面數代替形狀。保留自然石、土灰、木纖維的有限色差及磨耗，不用玩具飽和色或幼兒化比例。真古代材料的確定性不能從渲染效果反推。

## 1. `nativity-manger`：空槽與未知住宿空間

用途是看清可盛放的凹槽、內底、口沿和承托，再回到路2:6–7、8–20；不做原住宿建築的判定。

- 建模選定外包絡約1.10×0.64×0.48m，底面0；這是可走近的原創實體教具，**不是文獻給出的古槽尺寸**。石質選擇同樣屬創作，不由中文「馬槽」認定石、木、陶之一，也不聲稱只有這種槽能盛放嬰孩。
- 一個有實際壁厚的長形槽體，內腔圓角、口沿不規則但不尖銳；不使用平面貼圖假凹洞。目標壁厚約45–65mm（名義55mm）、內底不薄於45mm，由閉合幾何表達內外面。內底平區起始Y=.060m，最高口沿=.480m、最低可先取=.465m；槽深量內底到實際口沿，不能把外部總高當內深。壁厚按內外局部法線／截面量，石面擾動不得吃掉最小壁厚與底厚，圓角不能自交。內外輪廓由作者塑形，不臨摹未見館藏。
- 底面以寬實底落地，禁止四角懸空、架在裝飾碎石上或穿入地面。保持正面積的Y=0承托面，約.90×.45m可作起點，量實際接地投影而非整個包圍盒；不能只有一個最低頂點。一個連續閉合殼連外底、外壁、口沿、內壁與內底，不用開殼加浮底片。整體不得內藏嬰孩、動物、稻草或暗示已知襯墊的布層；空槽的節制必須在UI說明。
- **沒有拆層或開蓋操作**。使用旋轉、俯看與側看辨認內底、厚壁和底部；不能為湊互動加一塊虛構「原槽蓋」。
- 模型語義組至少分槽體與必要的固定承托；若槽體本身就是寬實底，不另增無功能底座。輸出必須量到內腔深度、口沿厚度、底厚、最低點及接觸面。
- 情境界線：路加牧人在野外先聽見，再前往；此教具不能證明槽原在洞穴、獨立牛棚、客店哪一層或親族客房。CSBT仍用「馬槽／客店」。

## 2. `nativity-home`：家屋日常的現代縮尺比較

用途是移開屋頂看門洞、室內地面和院落，作路2:39–40、51–52拿撒勒成長／返回的日常空間比較。十二歲耶路撒冷聖殿段另讀，不在小屋裡安放教師或講臺。

- 原創模型外包絡約1.10×0.80×0.40m（底盤包含在內），選定約1:10教學縮尺；尺寸不是IAA未取得平面的量測。家屋只有一個主要室內空間、一個真門洞和一處院落，避免讓玩具式分格變成已證實的家庭房間表。
- 現代薄底盤約25mm厚，有真底。牆用厚實分段石土灰體，門洞上有真過梁承托，門檻不可堵住開口；室內地面與外院地面都實際存在。選定模型牆厚25mm、門淨寬110mm、門淨高205mm為起始值；底盤不換算成古代250mm門檻。牆厚、門高寬及屋頂材料均屬原創選定。
- 唯一可移組名為`nativity-home-modern-roof-layer`，沿glTF[0,.18,0]抬起；只含一片有厚度的教學屋頂與其固定在同組的梁件。不得連牆、地板、院落或器皿一起抬。選定垂直帳：底盤0–.025、地面.025–.040、牆頂.360、梁.360–.380、板.380–.400m，抬起最高.580m。每根梁的兩端以真接觸面落在牆頂承座，板底接梁頂；不將梁埋進無開口牆體，不加內扣、向下鉤或燕尾阻止垂直提起。門楣底可取.245m，兩端各有至少20mm模型長度的實際搭承，上牆落在楣頂；門洞全深貫通。沿垂直20個樣本位置不可穿牆或門楣，還原不得穿插。拆開後露出室內，不只是多一條陰影。
- 縮尺物件只放必要的固定、無文字普通容器或存放台，按同一比例製作；不稱約瑟工具、聖家原物或家庭資產統計。不得內藏地下糧坑當馬槽，或將多時期墓葬／教堂遺跡裝成同時住家。
- 語義組至少分現代底盤、固定地板／牆／門楣／院落、單一屋頂層、固定比較物。報告包含真門洞、牆厚、屋頂厚度、梁牆接觸及拆還前後頂高。
- UI說明這是一個現代縮尺模型；場景中的人不按模型屋比例縮小。原創街區房舍可有日常層次，但不抄成已認證的原宅測繪。

## 3. `nativity-joinery`：木料與接合的現代構造比較

用途是讓使用者看到兩件木料如何接合，再區分現代結構選擇與可6:1–6對成年耶穌「木匠」的稱呼。**不製作完整古代工具箱、木刨或館藏A2468鑿的臨摹件**；目前沒有已目視的形制證據，館藏的現代配柄也不搬成古物。

- 現代比較底盤約0.95×0.62m，總高目標約0.19m，底面0。兩根粗實木料做一個清楚的半搭接示例；所選接法是現代教學構造，**本段經文沒有指定這種接合，也不以此認證拿撒勒古工法**。
- 固定木料沿X方向，另一根沿Z方向交叉；固定料從頂面切、移動料從底面切互補真凹口，不能兩料都從頂面切或用重疊長方體／黑貼圖假槽。選定底盤Y0–.030m；固定料長.780、Z寬.150，移動料長.460、X寬.150，兩者同底.030同頂.190m。固定頂凹口X寬.154，切至Y.110；移動底凹口Z寬.154，切至同一Y.110。各殘厚.080m，中心水平面實際貼合，側面每邊.002m製作間隙；公差不留在水平承托面，也不代表古代工法尺寸。兩料端底貼底盤，不能靠互穿或懸浮才看似組好。
- 唯一可移組`nativity-joinery-modern-upper-timber`沿glTF[0,.18,0]抬起，包含選定的整根Z向木料，不含固定木料、底盤或旁置固定材料片。「上方」指其跨接的上半部，不表示另疊一整根完整木料。抬起最高.370m、最低實體.210m，較固定料最高點高20mm。從不同俯／仰視角觀察互補凹口：下料凹口朝上、上料凹口朝下，不要求一張正俯視同時看清兩個凹底。20個路徑樣本不穿入，t=0正確接觸不當成穿透，還原後不懸浮。
- 表面可有有限木紋起伏與鈍邊，不能把凹槽做成危險鋸刃或讓玩家拿起打擊他人；沒有切削、掄工具、製作積分或兒童學徒的動畫承諾。若放材料片，只供比較木紋方向，必須真貼合自己的承托。
- 語義組分底盤、固定木料、單一上方木料、必要固定材料片。報告量測凹口底面、上下料厚度、互補空隙、承托接觸與逐頂點位移；不以AABB相交代替實際表面檢查。
- UI明示成年返鄉／會堂教導是可6敘事的核心，木料在另處作生活比較；不從這件教具補出約瑟帶童年耶穌在原工坊製家具、產品、工資或每日行程。
