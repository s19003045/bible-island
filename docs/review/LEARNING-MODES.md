# 三種學習流程檢視

完整流程先適用於摩西會幕、所羅門聖殿、新約時期的聖殿、以色列人出埃及、新約耶路撒冷。歷史模型共用；模式改變學習行動、引導與資料深度。其餘十九島明示目前只有文字導讀，可直接前往會幕體驗完整流程。

| 模式 | 進入時可見 | 實際操作與完成條件 | 人物對話 |
| --- | --- | --- | --- |
| 親子 | 三個觀察任務、當前問題與「前往觀察」 | 鏡頭走近探索點才開放作答。答錯給提示、可重試；答對顯示經文脈絡與復原限制。 | 每位角色提供對應物件的觀察提示與追問，可回到原任務。 |
| 一般 | 故事起點、各幕順序與「看這一幕」 | 觀看後呈現導讀、提問與 CSBT 經文；明確按「讀完」才記錄，並接續下一幕。 | 保留既有情境問題與完整解答。 |
| 研讀 | 三項待核對主張與對讀工作台 | 打開依據與限制，再分類為經文描述、歷史研究或復原推定。開啟資料本身不算完成。 | 保留情境對話，追加清楚標示「非角色發言」的研讀旁註與工作台入口。 |

研讀工作台可切換俯視與人物尺度，並並列比較相關場景的時代、尺度與復原取捨。札記只存本機；經文統一連到 YouVersion CSBT，不加入額外的經文全文。

模式偏好及各島、各模式的觀察、完成、資料開啟狀態與札記存於 `bible-island:learning-modes:v1`。不與原有的足跡、收藏及耶路撒冷小旅程完成紀錄混算。切換模式會結束當前交談／行走，顯示新流程與第一個行動；舊模式的學習進度保留。

一般模式維持既有耶路撒冷四階段步行旅程。親子與研讀的自由行走顯示對應學習提示及返回任務／工作台的入口，不要求完成與新對話不相容的舊旅程步驟。

導讀及親子對話的朗讀使用使用者主動啟動的瀏覽器中文語音。裝置沒有中文語音時提供明確文字回饋。既有耶路撒冷錄音只配對原本的台詞，避免播放與親子提示不同的內容。

檢視重點：切換模式後立即看見不同主標與行動；觀察前不能作答；錯答不增加進度；人物提示後能返回任務；一般導覽可走完最後一幕；研讀需查看來源後才可分類；模式切換與重新載入保留各自進度；手機版無水平溢出；鍵盤可操作並保留回饋焦點。

`tests/learning-modes.test.js` 覆蓋內容參照、所有親子任務的正誤與前置條件、一般導覽完整路徑、資料對讀條件、進度隔離與儲存、十五位角色、三種操作面板、札記跳脫、模式朗讀、步行返回與語音取消／不支援情況。

本次驗證：55 項測試、內容檢查及正式建置通過。瀏覽器逐一檢查五座島的十五個模式入口，並實際操作親子正誤回饋／人物提示、故事接續、研讀資料／分類／跨場景比較、重新載入後的模式與札記保存，以及親子自由行走返回。390 px 手機寬度的頁面與內容寬度一致，對讀視窗可開啟；瀏覽器錯誤紀錄為空。測試瀏覽器未提供中文語音，已確認顯示不支援的文字回饋；可用語音的播放與取消邏輯由模擬語音介面的測試涵蓋，未聲稱在此瀏覽器聽驗成功。

主要檔案：`src/learning-data.js`（內容）、`src/learning-model.js`（進度與條件）、`src/learning-ui.js`（流程介面）、`src/reading-speech.js`（選用朗讀），由 `src/main.js` 串接現有場景，並更新 `src/people-ui.js`、`src/walk-ui.js` 與樣式。
