## 原稿與直接讀過的經文

目前主題是「加利利的湖與村落／漁船上的生活」，總參照可1–6；三stop依序為boat「漁船與漁網」（1:16–20；4:35–41）、house「迦百農的家屋」（2:1–12）、synagogue「會堂」（1:21–28）。現有會堂導讀提「誦讀」，但**可1:21–28核心明說教導、驅趕汙靈與眾人反應，沒有記正在讀某卷書**；未來不可為舊stop一句概括導讀補出讀卷場面。

已直接完整讀到CSBT312的[可1](https://www.bible.com/zh-TW/bible/312/MRK.1.CSBT)、[可2](https://www.bible.com/zh-TW/bible/312/MRK.2.CSBT)、[可4](https://www.bible.com/zh-TW/bible/312/MRK.4.CSBT)，包含所指定四段及所在章的前後文。可1最後直接讀取的繁中頁為2026版權頁；可2、可4繁中入口一度返回較舊快取，因此又完整讀了同版312的[日文介面可2](https://www.bible.com/ja/bible/312/MRK.2.CSBT)與[可4](https://www.bible.com/ja/bible/312/MRK.4.CSBT)，正文仍是繁體CSBT，並非改用日文譯本。核心四段沒有待補讀缺口。未完整閱讀本輪範圍以外的可3、5、6，不把它們的其他事件擴成已審場景。

本輪詞表：**加利利湖、迦百農、西門、安得烈、西庇太、雅各、約翰、雇工們、漁網、經文士、汙靈、癱瘓的人、墊子、縋下、老師、船尾、枕頭**。經文引言與自行撰寫導讀分開，不能把導讀中的「擔架」「朋友」「伯多祿的房子」冒充這四段CSBT逐字稱呼。1章的西門不能在直接引文中自動換作彼得；經文士也不整批改名為法利賽人。

## 三章與時序：保留鍵，不把主題分組冒充連續日程

馬可的篇章先後為湖邊呼召（1:16–20）→迦百農會堂（1:21–28）→1章其他事件→過些日子又到迦百農的家屋（2:1–12）→較後4章的湖邊教導與晚上渡湖。**boat本身已有1章／4章兩個時刻，調換三個stop也不能使全島自動成為逐日時間線。**

建議預設章次採 **boat → synagogue → house**，保留舊ID，以便接續可1到可2；boat的風浪段必須明示「另讀較後的可4」，離開此段回看會堂時也有回看提示。若根代理要做完全依章次的連續故事入口，可另設「boat呼召 → synagogue → house → 回boat讀風浪」閱讀路徑，但不可暗改進度鍵或把到達熱點算讀完。原boat→house→synagogue也可保留作主題順序，前提是第三章清楚回看1章；本輪只建議，未決定或改app。

## 房屋、會堂、古船：不可混淆的幾條線

1. **文本房屋與紀念原址分開。** 可2說房子，註釋可譯家，沒有在該段給屋主姓名；可1:29另明說西門和安得烈的家，但不能因此直接認證所有迦百農房屋事件都在同一遺址。SBF房屋平面、後來教會記憶與後期改建需各自標示，不用一間名宅代表全村。
2. **拆通不等於原有活動蓋板。** 可2屋頂被拆通，沒有說原先有可滑開天窗、起重滑輪或整片可升降屋蓋。其他福音的屋瓦用詞不能靜悄悄改成馬可施工細節；現代教具可有抬開展示，但須明示這是觀察方式。也不把屋面復原成沒有厚度的一層貼圖。
3. **白石與黑石不能當通用年代密碼。** 較晚白石會堂、玄武岩基礎、家屋及再利用石料各有脈絡；不是所有黑石都一世紀、所有白石都同一期。可1建築的完整樣式、座席、樓廊分性別、卷櫃與裝飾未由本段交代，不能直接照搬後世會堂配置。
4. **古船的稱號不給所有權。** 古船的定年範圍、地點與可見木構是研究比較，不能由「Jesus Boat」俗稱跳成耶穌乘過、由某門徒所有或就是平浪那船。展架、保存木、缺失上部與後來復原須分開。沒有主張它完整保留一套帆、槳、漁網、枕頭或航行裝備。
5. **身體與群體不做敵人分類。** 可2不能轉成癱瘓皆因個人罪孽、信心不足就不會好，或現代身障者應受責怪；可1汙靈敘事也不直接拿現代精神疾病或抽搐者作妖怪標記。保留文本及其神學問題，不設打擊、抓捕、羞辱、抬人闖關或醫治計分。
6. **風浪不是兒童危險測試。** 可4保留門徒驚恐、提問及對耶穌身分的再問，不用溺水倒數、體感翻船或失敗懲罰代替閱讀。風浪／平靜可分文本狀態，但現代聲光不認證當晚天氣強度、時鐘或原聲。

## 日常NPC與三模式方向（僅提綱，不是台詞）

可用三位無名綜合居民；他們協助讀文本與看物件，不冒充西門、屋頂四人、被醫治者或被汙靈附身的人，也不聲稱目睹全部事件。普通居民衣裝可沿用同時期生活形式的有限資產，但網具／船工活動另驗；不以統一衣色或臉型區分「漁民／經文士／好壞群體」，也不以後期禮服認證一世紀會堂身份。

- **一般模式：** 以人正在做什麼、誰說話、他人怎樣回應為故事主線；到物件旁觀察後回讀完整段，不讓所有NPC只背「不能如何」的禁則。boat要讀兩個時刻，house要讀赦罪／治病後半，synagogue不能只剩空間說明。
- **親子模式：** 可問兩對兄弟各在做什麼；四人為何不能從門前抬近、後來那人拿起什麼出去；會堂裡眾人為何驚訝、最後怎樣談論。問題依指定文本取答案，不考未定船尺寸、猜病因、模仿抽搐、分誰比較有信心或強迫孩子扮患者。
