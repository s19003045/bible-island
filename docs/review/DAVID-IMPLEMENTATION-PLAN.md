## 依序實作

1. **牧養與受膏**：丘陵牧地、家庭外院、羊群與盛油犄角教具分層。羊有自主的停留／移動與接地，從既有原創羊來源重用但不定品種、性別、毛色或數量。玩家走公共觀察路線，無選王外貌測驗或替具名人物倒油。核心不加琴；若延伸撒上16:14–23，須另標CSBT「豎琴」及未定構造，不能宣稱牧場正演奏。
2. **山脊與建造**：原創山脊、坡道、堡壘輪廓、木石工作區和聚落遠景。木石教具拆的是現代構造層；大型石構、水道與梯壘不指定為大衛宮殿／攻城路。居民談木匠、石匠與不同受膏時刻，研讀資料另承認撒下5的身障污名與說話者，不將其做敵人標籤、排除規則或攻城玩法。
3. **遷移、中止與安放**：`ark`內再用互斥時刻選單，至少四個狀態：新車／俄別·以東家三個月／後段抬櫃／帳篷安放。切換同步更新場景、器物顯示、導讀與聲源，先停止原對話與行走。初始新車不顯示同時抬櫃與終點帳篷，後段不留出事故車列；三個月用文字時間卡，不以連續幾秒行走取代。烏撒之死用文字交代轉折，不驚嚇處刑，也不編其動機。撒下7獨立另讀未來建殿與家室應許。

三位無名角色分別談牧養／召回、木石與王城、遷移與等待，不自稱撒母耳、希蘭、米甲或第一手目擊者。章內時刻切換仍保留角色台詞的正確處境；需要跨時刻解說時由現代教學角色明說。人群沿用個別seed／速度／時鐘、POI容量、分離避讓、平滑轉向及3–6秒交談，不因換模型改成共享決策時鐘。

## Blender 交付與運送界線

預備 `david-shepherd`（羊與盛油犄角）、`david-city`（坡脊與木石剖層）、`david-ark`（分時比較）。模型須由正式主建置產出，保留可編輯來源、底高、尺寸、三角、雜湊、語意群組與渲染。隔離預覽只用於製作檢查，不代表正式來源已整合。

盛油犄角要有真內壁／內底，不能是吹號或實心封口；羊檢驗四足／蹄與地面接觸，不能以卡通球體代替。木石構造有厚度與可還原拆層，不造精確宮殿測繪。約櫃教具的各時刻群組可獨立顯示／隱藏，UI不能把四個群組全部當作同一實景；如同時比較，須明示現代分時比較。環／杠依出25、肩扛依代上15另標跨卷來源；杠固定不抽出，無開櫃取物、扶櫃致死按鈕。六步不畫成六位抬者，櫃體與覆布仍為原創補足。

優先借用已製作的素衣／工匠身體與骨架，明確處理`david` appearance以免落入第一世紀預設；若重用`priest-bearer`，要另外驗證大衛段落行進姿態及服裝，不能把約旦河站立祭司直接稱同一歷史人物。不得以民族臉型或固定衣色分群。
