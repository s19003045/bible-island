# 耶路撒冷：走進山城的一天

這是五座重點島的原始技術基準；2026-11-15 已接回共用探索入口、三模式、物件返回及配音架構。原有 50 位 NPC、24 個 POI、57 個容量站位、四階段小旅程和本機進度保留。會幕、所羅門聖殿、希律擴建後第二聖殿及出埃及三段也已有自由探索，見 [依序套用計畫](../FOCUS-ISLAND-ROLLOUT.md)。

## 操作

在新約耶路撒冷側欄點「開啟聲音，走進街區」，或選「安靜探索」。

- 電腦：WASD 移動，拖曳環顧；方向鍵上下前後移動、左右轉頭。點「自由環顧」可嘗試滑鼠鎖定；不支援的環境仍能拖曳。
- 手機：行走按鈕與轉向按鈕可按住，亦可在場景拖曳環顧。
- 點可步行地面會沿路前往；「沿路前往」會尋找當前任務目的地的路線。WASD 或「停止自動行走」可接手。
- 走近角色後按 E 或互動按鈕；行走角色會停步回應接近。對話中停止移動，結束後可繼續探索。
- 「回到全景」或 Esc 離開行走。Esc 在對話或視窗中會先關閉目前面板。

玩家視高為腳下地面以上 1.65 m。先開放主街、兩條橫巷、四段連接巷、一處院落與入口石階平台；這是有界的公共街區示範。它不是完整城區的導航圖，也沒有開放所有屋內、屋頂或城外山坡。路線與模型均屬類型復原。

樓梯與矮階的接地、坡度限制和鏡頭平滑，詳見 [角色控制器說明](./CHARACTER-CONTROLLER.md)。

## 一段小旅程

1. 走近提水居民，詢問山城坡路。
2. 沿巷弄走到院落，分別觀察陶製水罐與石製器皿。器物可拖曳旋轉或用方向鍵／按鈕轉動，附觀察提問及研究入口。
3. 詢問住戶內院用途，再追問不同家庭的房屋差異。
4. 完成觀察題，留下閱讀札記。錯答會給提示，不會清除先前進度。

任務不依賴聲音；完整字幕、選項與資料連結都能閱讀。完成紀錄只保存在目前瀏覽器，以獨立的 `bible-island:jerusalem-walk:v1` key 儲存，不會改寫既有收藏、主題或探索點紀錄。可重開任務，也可忽略任務自由探索。

## 聲音與配音

音訊必須經使用者啟動。環境／腳步、人物語音及背景音樂三個音量可分別調整或完全關閉。角色說話時環境音降低；關閉對話、切換主題或頁面隱藏時停止語音。

環境音為原創程序合成的風、布棚聲及鳥鳴；腳步依主街或巷道使用不同濾波。角色語音與局部聲源以 Web Audio 空間定位，隨觀察位置與方向改變。可選擇播放共用的現代原創背景音樂，對話時降低音量；沒有宣稱重現古代實際聲景或古代曲調。

三位角色使用 HeyGen Voice 製作現代中文情境配音，共 15 段對話音訊區間，分別存放在三份本機 MP3 內；播放以解碼後時間碼指定區間，不依賴遠端生成網址。原始台詞、實際 voice ID、模型選擇方式、生成時長與時間碼保存在 [配音製作紀錄](./JERUSALEM-VOICE-PROVENANCE.json)。選用的公開聲音目錄地區為 zh-CN，沒有宣稱是臺灣口音或古代語言。台詞已與回傳字元對齊資料核對；仍待真人完整審聽人名、地名、語氣與發音。

## 技術與驗證

- `walk-data.js`：公共路線、物件與任務狀態；`walk-model.js`：膠囊水平投影碰撞、空間格與 A* 路徑。
- 靜態模型批次的幾何外框提供碰撞範圍；前進分段計算，防止大時間步穿牆。路徑禁止斜穿狹窄轉角。可步行地面依坡度與地形連續取高，限制在已設計的街區內。
- `walk-controls.js` 管理鍵盤、拖曳、指標鎖定與可中斷的自動行走。失去焦點會清掉按鍵；交談及視窗會封鎖步行。
- `scene-audio.js` 管理聲音啟用、增益、空間定位、解碼快取、切段及取消。`vessels.js` 共用場景器物與近景模型，關閉近景釋放其 WebGL 資源。
- 自動驗證包含牆與邊界、真實場景完整路徑、桌子碰撞、視高與輸入凍結、任務條件，以及三位角色所有台詞對應的本機配音。

原始示範階段的本機驗證：21 項測試、內容／語法檢查、正式建置與單檔試閱打包均通過。另以瀏覽器實際完成任務、角色語音播放、兩種器皿觀察與旋轉、答題提示、閱讀札記和重開後的紀錄保留；390 × 640 畫面確認無橫向溢出，按住手機方向鍵可移動。最後另補低幀率反覆尋路的回歸測試，避免被拉回上一個格點。指標鎖定與各型手機尚未全面驗證。

視覺仍是程序模型，沒有加入玩家第三人稱角色、嘴形同步或建築內混響。耶路撒冷已加入 [POI 自主行為與動態避讓](./NPC-BEHAVIOR.md)。步行與音訊品質以本機瀏覽器試玩結果為準，尚未全面測試各種手機與耳機。

這輪供本機試閱，沒有部署 Sites。


## 2026-11-16 五島整合更新

- 親子／研讀步行介面新增三位人物與兩件器皿的沿路前往入口，並保留返回各自學習流程的按鈕。一般閱讀仍使用原有四階段小旅程。
- 陶器／石器近景保留旋轉、互相比較、研究入口與類型復原說明；新增回到「住家與屋頂」探索點與目前閱讀模式。觀察器物不會直接完成讀經、觀察答題或來源判斷。
- 三位角色各新增一份親子 MP3、三段台詞，共九段。本機檔案量測：住戶 19.173875 秒、居民 19.539563 秒、商販 16.692188 秒。沿用原版同一組目錄聲音與 1.0 倍速，原版三份 MP3 及十五段時間碼以 SHA-256 契約檢查維持不變。新增來源、完整回傳時間碼及文字見 [親子配音製作紀錄](JERUSALEM-CHILD-VOICE-PROVENANCE.json)。完整真人審聽及專名讀音仍待確認。
- 共用音訊依實際檔案 URL 快取，避免同一位角色的一般／研讀與親子台詞誤用不同錄音；沿用最多四份解碼快取、取消及隱藏靜音。自包含試閱包亦納入每段指定的親子音源。
- 舊 `bible-island:jerusalem-walk:v1` 讀寫規則抽成可驗證函式，仍保留原 key、所有合法階段與完成條件；未知器物與不合法完成資料會清理。沒有更換既有收藏、觀察、模式進度或札記 key。
- 修正人群測試發現的窄巷問題：分離力可能把 NPC 推上相鄰外梯的側邊並逐階升高，與街道路徑脫離。人物移動現在核對指定導航表面高度；50 人成熟人群的院落導引已可抵達，並維持接地與玩家分離。

多數居民現在分屬主街、北巷或南巷，少數往來者與提水居民跨區；50 人、24 POI 與 57 站位不變。避免所有居民反覆穿過同一窄巷，並保留職分、空位預約和獨立計時。遇到持續阻擋時，人物可沿實際路徑退讓至另一個空閒 POI；此路徑保留避障轉折，不被短距離路徑前看直接切回阻擋者。

新增四項耶路撒冷整合測試、一項音訊切換測試與一項共用 NPC 窄道退讓測試，涵蓋舊任務相容、原檔／原時間碼契約、九段親子配音、模式操作及成熟人群院落導引。93 項完整回歸、內容檢查、正式建置及離線試閱通過；最終瀏覽器完成器皿返回、三模式、四階段旅程、跨島後保留紀錄及 390 px 操作。完整證據與限制見 [五島總驗收](FIVE-ISLAND-ACCEPTANCE.md)；本次沒有部署 Sites。
