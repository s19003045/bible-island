## 1. 三個舊鍵可保留，閱讀順序不等於寫作年代

| 舊鍵／現有參照 | 可保留的三章方向 | 必須分清 |
| --- | --- | --- |
| `desk`／書寫與文書，羅16:22 | 羅馬書中的作者、代筆者、問候與收信群體 | 羅1自署保羅，16:22特提烏斯自稱代筆；不是所有書信都由此人寫，也不表示本輪找到保羅或特提烏斯的原稿／原書桌 |
| `messenger`／送信的人，歌4:7–9 | 轉入另一封書信：被派的人、同行者、消息與安慰 | 信中預告特其庫斯與奧尼斯莫會使收信者知道近況；沒有交代紙材、封裝、交通、路線及時長，不把羅16的代筆者搬入同一送信現場 |
| `reading`／在群體中朗讀，歌4:16 | 收信、宣讀與跨群體閱讀的囑咐 | 先在收信者那裡宣讀，再在勞迪西亞教會宣讀，並讀從那裡轉來的書信；這是信中的指示，不是已取得各地照辦的獨立紀錄 |

原 metadata「歌羅西書4；羅馬書16」可保留為核心入口，但設計不應宣稱只讀這兩個尾聲便已解釋全卷。`desk` → `messenger` 是**從羅馬書轉讀歌羅西書的教學次序**，不是判定兩卷依次寫成，更不是沿同一桌邊走到隔壁房間。`messenger` → `reading` 可以保持歌羅西書內的收信／閱讀關係，也須區分歌羅西、勞迪西亞和未指定的寫信地點。

現有 `letters` 與 `gathering` 共用兩屋、兩桌、環列七人及一樹的通用模型。它不提供古代文書室、教會聚會平面、座次、使徒人數或寫信城市的考古證據，也不是第24島已詳細實作。

## 3. 先分角色與文件，不把所有人合在一間監房

| 問題 | 經文直接給的範圍 | 仍未證成的細節 |
| --- | --- | --- |
| 誰在寫／向誰說？ | 羅1:1、7介紹保羅與羅馬的收信者；羅16:22特提烏斯代筆。歌1:1–2列保羅、提摩太及歌羅西聖徒；歌4:18自稱保羅親筆問候 | 自署、協作與實際持筆是不同問題；未給每句如何口授、誰修改措辭。不能據此說保羅完全沒有動筆、特提烏斯是獨立作者，或提摩太親寫每一行 |
| 誰傳遞？ | 歌4:7–9派特其庫斯前往，奧尼斯莫同行；預告他們會傳達近況，派遣也為安慰收信者 | 從此推想兩人參與送信有語境理由，但本段未逐字寫他們手持哪卷、是否另有副本／信袋、誰逐字朗讀或解釋全信；不能把合理推論升成原稿交接照片 |

| 哪些人被問候？ | 羅16:3–16列收信一方的同工、家中教會及不同群體；21–23又列送出一方的問候。歌4:10–14亦有多名問候者 | 不能把兩側名字一律畫成寫信桌旁的全體合照，或把問候名單當某一家庭、某一夜所有聽眾的精確名冊 |
| 何時、哪裡？ | 羅1及15表達仍盼望去羅馬，15:25–32提當前往耶路撒冷服事與後續計畫。歌4:3、18提捆鎖，10提同坐牢者，但本段不寫監房地址 | 不因書名羅馬書便說寫於羅馬，不把它與歌羅西書都固定在同一年羅馬監房；不把往西班牙的盼望演成此處已完成。精確城市、年分、囚禁階段與作者研究未在本輪裁定 |

書信中的自我介紹與結尾是本輪可直接核對的文字證據；它們和現代研究對作者、合作者、代筆及寫作處境的推論應分層。本輪不以單一房間模型裁斷歌羅西書等卷的作者／年代問題，也不虛稱學界對所有細節已有一致結論。

## 4. 三章十個可選閱讀窗口

| 章／窗口 | 建議參照與閱讀動作 | 時刻／語義界線 |
| --- | --- | --- |
| desk 1：先看誰向誰寫 | 羅1:1–15與15:22–33；分辨自我介紹、收信者及計畫 | 寫信不是保羅已到羅馬後對同房人發言；「想去／希望」保留未來語氣 |
| desk 2：信連著哪些人 | 羅16:1–20；推薦、問候與群體勸告 | 女性同工、家中教會和不同名字有其文本位置，不靠性別／膚色／衣色分類誰能讀寫 |
| desk 3：代筆與結尾 | 羅16:21–27；特提烏斯後記、同工問候、祝福 | 代筆不是改成另一封信，也不從這一句推出整套口授／校訂工程；保留完整16章閱讀出口 |
| messenger 1：換讀歌羅西書 | 歌1:1–8、2:1–5；寄信自署、收信群體與身體不在場 | 可另開全卷；明示已換文件，不說特提烏斯正寫歌羅西書 |
| messenger 2：為何需要消息 | 歌4:2–6；禱告、捆鎖與有恩惠的回答 | 捆鎖是書信處境，不指定鎖鏈工程／牢房，亦不把對話只剩交通工具 |
| messenger 3：被派的人與同行者 | 歌4:7–9 | 區分被派、同行、近況與安慰；原字形、袋印、交通費都不是經文明載 |
| messenger 4：問候連起同工 | 歌4:10–14 | 問候者與收信者不畫成同一屋；同工身分與會面日期不從一張名單補齊 |
| reading 1：家中的群體 | 歌4:15 | 寧法家中教會不自動等於歌羅西第一個收信房間；不套後世大教堂 |
| reading 2：宣讀與轉來的信 | 歌4:16 | 依囑咐分清在你們那裡、勞迪西亞、轉來信的方向；不把不同地方所有聽眾塞同一桌 |
| reading 3：不只交到手中 | 歌4:17–18，回連3:12–17 | 服事提醒、親筆問候與記念捆鎖接回群體生活；收到／宣讀是指示的內容，不宣稱本輪已找到其實際履行記錄 |

這十窗是可選閱讀安排，不是已實作狀態或考古已驗的十次現場。三章應保留回到經文的目的：被提醒、受安慰、彼此教導與承擔生活，不以完成物流關卡取代閱讀。

## 6. 三件原創現代教具的可選方向

以下不是製作brief，不定稿尺寸／造型，不授權建模、生成或錄音。所有可動件、站位與文字片屬現代教學設計，不能冒充原出土文物。

| 章／方向 | 可供Blender原創且可驗的幾何 | 文本與實物的界線 |
| --- | --- | --- |
| desk：書寫材料層次比較組 | 紙草示意以可見交叉條層／薄片邊緣呈現；旁置薄木墨面與具有真凹面的木質蠟板，分別對應墨寫筆／尖筆。可拆分剖面與承托台，查看凹陷、層厚、接地與握持空間 | 是機能比較，不說這三件都在羅16書桌上，也不把所有紙草都做成雙軸長卷或裝訂冊。筆跡保持空白；若放示意痕跡／現代中文標籤，必須明示非特提烏斯、保羅、Severa或P46原字 |

## 7. 綜合NPC、三模式與倫理範圍

| 無名綜合NPC方向 | 三個話題 | 追問方向 |
| --- | --- | --- |
| 日常文書協作者 | 誰自署、誰代筆；信末的不同問候；墨寫／刻寫材料比較 | 一份文件能否有多個參與者？不是自稱特提烏斯或代寫全部使徒書信 |
| 行旅與交付協助者 | 被派與同行；近況及安慰；文件之外的人際信任 | 經文告訴我們什麼，哪些交通／封裝仍不知道？不只談路程或自稱原始信差 |
| 聚會的接待／聆聽協助者 | 家中的群體；宣讀與轉來的信；服事提醒與彼此生活 | 先在哪裡讀、還應讓誰讀？不能把不同群體都塞進我的屋子或把收到信當讀懂全文 |

- **一般閱讀：** 以羅馬書認識書寫協作，再明示轉卷到歌羅西書；近況、安慰、宣讀與生活教導相連。書信不是一份各卷同步發生的劇本，更不是唯有找到紙草才能理解的工程問題。
- **親子：** 觀察材料凹面／層次與兩種書寫動作，再找特提烏斯的代筆後記；觀察交付位置，辨認誰被派、誰同行及他們帶來什麼；觀察分離閱讀架，照4:16分辨閱讀方向。錯答給經文線索，不考古代筆跡辨識或要兒童扮奴僕、交付人物、強制親吻禮。
- **研讀：** 經文描述可選羅16:22代筆、歌4:16宣讀指示；歷史研究可選RIB291的木墨材質／97–105年英國脈絡；復原推定可選兩封原信的外形、路線／速度、書桌／聚會屋配置。P46是後來抄本的機構研究，不能用它的冊葉形制直接認證1世紀寄信原稿。
- **奴役與權力：** 歌3:22–4:1與腓利門書涉及真實不平等；腓利門書請求以弟兄接納、送回與償還的文字不能美化為沒有強制性的普通僱傭。也不能直接補成奧尼斯莫已獲法律釋奴、一定偷錢／逃跑、或本島已解決整個古代奴隸制度。兩卷的人名／同工關聯可提出，但不能只憑關聯便認定同地、同日、同一信袋。不得讓玩家追捕、買賣、懲罰或決定交出某人；父權、順服、捆鎖與受苦不作強迫當代受傷害者默受的任務。
