# 自動步行路線與視窗切換

2026-11-17。撒馬利亞近景補驗時，畫面顯示主角停在出生點與教具之間，導航提示已回到手動移動。程式確認`blur`及`visibilitychange`共用處理器同時清除按鍵和`route`；獨立事件重現由`navigating:true`變成`false`。這是已選自動路線被失焦取消，不能只歸因瀏覽器操作逾時。

`walk-controls.js`現在失焦只釋放鍵盤、觸控軸、轉向及拖曳，保留自動路線與目的地。頁面隱藏仍由`world.js`暫停模擬，不在背景補算消失的時間。恢復可見後沿既有可走路線接續；「停止」、手動按鍵接管、結束探索、模式／分章切換、交談及近景視窗的既有取消／鎖定不變。不是新增傳送、加速或免碰撞模式。

新增回歸先在舊處理器失敗，再在修正後通過；同時驗證失焦後釋放手動移動與轉向、明確停止仍有效。原步行8項與撒馬利亞6項整合已通過；完整全站結果及發布在下方追加。瀏覽器操作另以實際位置、路線提示、互動距離與近景檢視記錄，不由事件模擬推定所有裝置體驗。

42檔共274項全站回歸通過，failures=[]，含Vite實際本機連線檢查；內容與語法檢查亦通過。本機熱更新後重新進入道路，DOM實際位置由18.166／16.657前進至16.716／9.566，期間返回工具與視窗後仍顯示「沿路行走中」。這證明路線未被切換視窗取消，但不等同已抵達教具或所有裝置的效能驗收。
