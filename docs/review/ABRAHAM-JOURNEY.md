# 亞伯拉罕的旅程：第九座詳細島

2026-11-16。按創 12、18、21 章分別呈現旅程築壇、帳棚接待與井水協議，沒有把三段當成同一天的營地。原 `altar`、`tent`、`well` ID 保留，排序改為經文先後，舊收藏及已讀紀錄相容；其他十五島仍接續，完整 Goal 保持進行。

## 文字依據與復原界線

- [創 12:6–9 · CSBT](https://www.bible.com/zh-TW/bible/312/GEN.12.6-9.CSBT)：這段稱亞伯蘭，依序辨認示劍、伯特利與艾城之間的山地，再往南地。石壇沒有經文明定的工程圖；未將後來的四角壇或會幕工程直接移入。
- [創 18:1–15 · CSBT](https://www.bible.com/zh-TW/bible/312/GEN.18.1-15.CSBT)：正午、帳棚入口、樹蔭、水和食物，以及亞伯拉罕、撒拉與僕人的分工。撒拉的笑、疑問與害怕保留在對話，不改成答錯扣分；三位訪客不另加翅膀。兩塊餅為教具選擇，三細亞不是三塊餅，沒有宰殺互動。
- [創 21:22–34 · CSBT](https://www.bible.com/zh-TW/bible/312/GEN.21.22-34.CSBT)：先有井水爭議與交涉，再有起誓協議，七隻母羊羔另放作挖井見證。沒有把牠們畫成祭物或偽造契約文字；同章夏甲與以實瑪利被逐、缺水及哭泣的傷害有明確旁註，不做排斥弱者任務。創 22 另讀，沒有獻子互動。
- [Met 拉吉中青銅碗 34.126.12](https://www.metmuseum.org/art/collection/search/323122) 與 [陶壺 34.126.32](https://www.metmuseum.org/art/collection/search/323142) 是區域器形比較，不能據此認定列祖年代或當事人的家庭用品。[Tel Beer Sheva 國家公園](https://en.parks.org.il/reserve-park/tel-beer-sheva-national-park/) 有不同時期遺存，鐵器時代角壇及現場深井不直接指認為亞伯拉罕原物。

上述章節與博物館／公園資料已讀取核對。樹種、人物面容、服裝、帳棚工程、道路、井深與砌法、祭壇尺寸都保留為復原選擇，不指定列祖絕對年代或精確坐標。人物是無名綜合教學角色，配樂與中文語音是現代創作。

## 空間、行為與學習

每章有公尺尺度的山地、分層遠景、帳棚／繩索、樹蔭、日用器皿、山徑、邊緣植被和岩群。接待章另有較近的大帳棚，井邊章有七隻分開的羊；三章各自使用一位可交談角色、對應觀察物及不同坡面。近處地表加密並有真正頂點顏色，避免共用材質卻缺顏色造成黑面；平滑碰撞地面與實際渲染地面對齊。

每章 13 位自主人物，8 組 POI／16 個容量位置。沿用個別 seed、速度、狀態時鐘、容量預留、分離避讓、平滑轉向和短暫交談，沒有群體計時器或 random walk。帳棚含繩索的碰撞邊界、樹幹、器物與羊群保持可通行路線；不同更新率下坡維持接地及 Y 軸平滑。三章有各自的空間聲源、泥土地腳步，配樂／環境／語音音量獨立，也可全程安靜探索。

親子先觀察並問角色，再解題；一般按章閱讀；研讀分辨經文、比較資料和復原推定，可與出埃及對讀。各島、各模式和器物觀察分開保存，觀察器物不直接算已讀經文；CSBT 連結可逐段開啟。

新增三個獨立人物骨架，各五種動作；三件器物及一種羊。總來源重開確認 52 個非空場景、25 個獨立人物骨架，無 QA 相機／燈，網格有限；七份新素材已渲染並逐張檢視。走路披布穿插修正為後肩布，羊的臉、耳與毛面另作細化；仍有風格化特徵，沒有宣稱照片級復原。
