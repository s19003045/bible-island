# 群島全景：連續海域與閱讀連結

2026-11-15。本機首輪整合；先於下一座重點島完成。位置、橋樑及航線均為閱讀導覽象徵，不是歷史地圖、古代道路或可測量的旅程。

## 本次可操作內容

- 24 座島依五個時代群組重新配置，保留原島 ID、收藏、讀經進度及深度場景座標。
- 連續海面延伸超過相機遠裁切面；遠方水色與天空融合。靜態岸距紋理提供不規則近岸淺水，搭配微波、礁石與船隻。平移限制在群島範圍，縮放仍可自由操作。
- 23 段常駐主線連通全部島嶼；另有四段聚焦關係。石橋、時代廊橋、海上虛線與比較弧線分別表示閱讀關係。連結不穿越無關的島嶼。
- 五個閱讀路線選項：群島主線、出埃及與會幕、聖殿演變、耶穌與耶路撒冷、使徒與書信。路線構圖依投影及實際螢幕比例計算。
- 點橋或航線可開啟關係卡，也可用原生按鈕清單操作；「沿路前往」沿連結移動後進入目的島。手動操作、換路線、篩選或切頁可取消。減少動態偏好略過跨島飛行。
- 比較弧線提供兩島的閱讀背景與 YouVersion CSBT 經文入口。三模式保留各自的閱讀提示；全景移動及比較不會自動完成學習任務。
- 開場文字在探索後退場，路線卡可收合；聚焦路線只顯示相關島名。手機縮放工具與路線卡分開，展開清單可捲動。

## 範圍與取捨

本輪連結可點選及轉場，尚未實作跨島步行或真實搭船操作。海面使用程序式著色與岸距紋理，不使用水體物理模擬。地形是閱讀空間設計；各詳細島的歷史來源、進入界線與模型尺度繼續由其復原說明管理。
