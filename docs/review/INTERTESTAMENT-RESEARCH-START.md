## 主題定位：三個新約窗口，不是四百年空白

舊 metadata 稱「波斯至羅馬時期」，總參照為但以理書／路加2；三個實際stop卻全是新約敘事。建議保留鍵及 `road` → `coin` → `scroll` 順序，但導讀明說：**藉新約三個不同時刻，回看帝國行政、錢幣與語言／書寫的歷史背景**。它們不能直接當成整個波斯、希臘化、哈斯摩尼至羅馬時期的完整通史，也不是同一城、同一群人一天走完的三站。

「兩約之間」是基督教閱讀安排的名稱，不等於當時沒有歷史、猶太社群沒有寫作或神已被考古證明停止說話。死海古卷保存了這一大時段中的宗教文學；文本保存、各宗教正典範圍與神學所說的沉默是不同問題。避免把「四百年沉默」當客觀歷史年表或對猶太信仰的概括。若整合時仍以但以理作總參照，須另做該卷的指定閱讀；本輪沒有完整核讀但以理，也不宣稱已研究每個帝國轉換。

## CSBT取得程度與關鍵詞

已直接讀到核心三段完整正文，並閱讀其前後脈絡：路2全章1–52、可12全章1–44、徒21全章1–40及徒22全章1–30。路2、可12的初次頁面輸出尾段不完整，另以同版[路2日文介面](https://www.bible.com/ja/bible/312/LUK.2.CSBT)及[可12日文介面](https://www.bible.com/ja/bible/312/MRK.12.CSBT)補讀；正文均仍為繁體CSBT312。個別章內範圍URL曾工具拒讀，沒有以它冒稱取得新正文；核心由完整章頁核對。正式UI仍用上表繁中312入口，跨章必須拆開。

- **路2**：本版人名是凱撒奧古斯都、居里尼烏斯、約瑟、瑪麗亞；地名為敘利亞、加利利、拿撒勒、猶太及伯利恆。1–3節沒有道路工法、里程、旅時或交通工具；不能補成經文明說驢、羅馬里程碑或全程鋪石。後面的降生、牧人、上聖殿與十二歲逾越節又是不同階段，不塞入一個登記日。諭令的普遍措辭不等於本輪已找到同一天覆蓋整帝國、每省程序完全相同的檔案。
- **可12**：核心稱「銀幣」，註明原文為得拿利；「約一日工資」是譯註比較，不能當跨地區永久固定薪資、匯率或現代幣值。問題是誰的像與名號，回答為凱撒；本段沒有直接點名提比留。前面的抓捕意圖、後面的其他辯論及末段寡婦奉獻各有脈絡；兩個小錢不是這一枚銀幣，也不是戶口登記費。法利賽人、希律黨與其餘群體不統一做成某民族的反派臉型。「神與凱撒」的宗教詮釋不縮成今日一條國家法律、無條件服從帝國或拒稅的通關正解。
- **徒21–22**：本版寫希臘語、希伯來語、奇里乞亞、塔爾蘇、千夫長、營樓及臺階。先被詢問是否懂希臘語，再獲准向民眾發言；22:2記人群更加安靜，不能說之後永遠不再反對。21:38的埃及人與四千凶徒是千夫長的誤認問題，不能變成保羅帶領的已證實人數。21:29也明說把特羅費摩帶入聖殿是他人的推想；不能將推想改為旁白已證實的行動。
- **語言不等於文字或國籍**：核心保留CSBT的「希伯來語」，不自行改譯亞蘭語；也不以現代希伯來語／希臘語發音檔認證當日口語、口音、方言或說話者的民族。外部書卷能證明不同文字與語言的使用，不能直接解決本句古代語言稱呼的所有學術問題。會說希臘語不等於是希臘民族或羅馬公民；後續羅馬公民權的交涉要另外讀，不能推成全帝國人人有同樣保護。

核心閱讀仍是經文敘事；帝國制度比較屬歷史研究，道路／錢幣／書卷外形屬有限實物比較，讀者如何理解神與帝國、身分及信仰屬詮釋。不能用一件漂亮模型把這幾層合成同一種已知事實。

## 後續台詞／學習可用的三個問題

- `road`：「這段先說誰的命令，接著哪些人需要移動？」回到文本和家庭處境，再分辨英國道路／埃及文書的比較；不讓兒童從路層猜出約瑟的精確旅日。研讀可把「這件路剖面的尺寸與材料組合是現代補足」分類為復原推定。
- `coin`：「耶穌請人看銀幣上的哪兩類線索？」回到像與名號；放大模型只協助找兩面，不以辨出館藏皇帝鑄模作經文正解。研讀可把館藏的地點、尺寸和年代列歷史研究，同時說明它不認證福音書原幣。
- `scroll`：「保羅分別在向誰說話？經文怎樣稱所用語言？」保留被押與獲准發言的前後，不用民族刻板印象猜語言。研讀可把核心的希臘語／希伯來語用詞列經文描述，與外部語言學推論、現代卷片模型分開。

行政命令、納稅交涉與軍事拘押都有權力差異；不編成帝國文明替所有人帶來同樣便利的宣傳，也不自行補造每位旅人的受害細節。徒21–22的毆打、捆綁及後續鞭打威脅可用審慎文字交代，不做兒童暴力、逼供、族群仇恨或選誰受刑的操作。神學對話保留文本與詮釋層次，不把一種今日立場當唯一歷史答案。配音及背景聲仍只能是現代創作，不認證古代希臘語、希伯來語、亞蘭語或拉丁語原音。
