## 建置與瀏覽器紀錄

`npm run check`、`npm test`（93 項全數通過）、`npm run build`、`npm run review:bundle` 及 `git diff --check` 均通過。建置仍有既有 Three.js 共享檔約 530 KB 的大小提醒；未為移除提醒而更換渲染器。

自包含試閱：`.qa/five-islands-review.html`，約 23,597 KiB。逐檔比對確認十八份本機音訊均已嵌入；經文和研究外連仍需網路。`.qa/` 為本機忽略產物，正式輸出為 `dist/`。

各島完整操作及畫面見 [會幕](TABERNACLE-WALK.md)、[所羅門](SOLOMON-WALK.md)、[希律聖殿](HEROD-WALK.md)、[出埃及](EXODUS-WALK.md)、[耶路撒冷](JERUSALEM-WALK.md)。最新城市驗收包含原版／親子配音啟動、四階段旅程實際走完、陶器／石器比較與旋轉、錯答提示及閱讀札記。

最終瀏覽器逐一切換五島的七個場景（出埃及三段），每場景各操作親子／一般／研讀，共 21 組進出；每組皆確認出生點接地、聲音關閉、返回後完成數保持不變。會幕與所羅門原有的部分完成進度也保留；城市原四階段旅程在跨島後仍顯示完成及札記入口。詳細本機紀錄存於 `.qa/five-islands-browser-audit.json`。

## 實際限制

- 模型與動作仍是程序建模，未加入第三人稱主角、真人掃描、骨架上下階、嘴形或室內混響；沒有 AI 自由對話。
- 已核對可查來源與復原限制，尚未經獨立聖經歷史學者審稿。畫面與連結存在不等同歷史認證。
- 配音的文字、檔案、時間碼與播放行為已驗證；完整真人審聽、語氣及專名讀音仍待確認。聲音目錄為 zh-CN，不宣稱臺灣口音或古代原音。
- 窄螢幕是瀏覽器尺寸檢查，不等同實體手機多點觸控、耳機、固定 FPS 或所有裝置效能驗收。減少動態與失敗回退已有程式／測試覆蓋，未在本輪改動使用者的系統偏好。
- 本機進度沒有登入、後端或跨裝置同步；正式 Sites 發佈須另行執行並檢視已發佈網址。
