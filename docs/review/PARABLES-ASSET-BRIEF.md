# 第21島隔離教具設計

2026-11-17。先讀 [研究起點](PARABLES-RESEARCH-START.md) 與 [實作計畫](PARABLES-IMPLEMENTATION-PLAN.md)。此稿只授權三件**隔離原型**及證據，不授權主builder、正式`.blend`、`public/models`、app註冊、音檔、Git或Sites變更。Root仍須親看實際GLB圖後另授權正式整合。

所有尺寸為現代桌面比較的選定公尺，不由肘換算，不認證原田、原計數器、羊種、婚禮器型、油量或燃燒時間。原創幾何、頂點色與粗糙度，不下載或臨摹館藏未目視圖片。每件目標≤30000三角形／1.6MB，確有需要先說明；三件材質要有清楚明暗、可辨前後層次，避免在瀏覽器變成難讀的淺色空板。

## 1. `parables-soil`：落處、土淺與根的現代剖示

約1.15×.75×.30m。四個並置比較位：踏實路邊、薄土覆實岩層、荊棘與土層、較深土與穀作。不是四塊等面積原田，也不是固定播種流程。薄土與連續岩層從前側剖面可讀，不能只是土面幾顆石。普通原創種子若放大，元資料明列為放大觀察、非已識別穀種與原尺寸。穀葉／荊棘有真厚度、底部承托與有限細節，不做懸空無根或穿過實岩的模型。

可有一個現代可移開的剖示層；只在能證明整組所有後代都跟移、固定組不動、接觸合法、20取樣不穿透、可還原時提供。若根形資料不足，可用剖面上的原創材質線表示根的關係，不把它當已挖出／量測的古根。土深、岩層、根線及三種收成倍數不能宣稱是考古量測。不得加入鐮刀來偷接可4:26–29，亦不做射鳥或燒荊棘操作。

## 2. `parables-flock`：一百、九十九與一的閱讀比較

約1.15×.75×.12m。固定99個同尺寸中性小籌作一組，另1個**同尺寸**籌在獨立閱讀區，總數精確100；排法只是現代閱讀法，不是古代牧人器物或羊隻物理大小。區間留足空隙，籌皆有真厚底、正面積承托、逐件不重疊；現代板底閉合，不用黑薄片假空腔。

可選1枚從「尋找」閱讀位移向「找到」閱讀位，但**不得移回99枚中**，因路15沒有交代牧人先把一隻重新放回曠野那群羊。這是現代閱讀標示，不是玩家抓羊、揹羊機械或比喻原路線；若移動沒有必要，保持靜態亦可。從尋回仍須回讀回家邀人同樂與第7節，不用盤子取代人的回應。場景另外重用既有細緻骨架羊；本資產不是新羊種雕塑。

## 3. `parables-light`：照明類型、油瓶與預備

約1.15×.80×.65m。分開呈現**原創功能比較**的小陶燈、供油火把概念及獨立油瓶，清楚留白，不拼成可證實的同一套古代婚禮裝備。Met條目只支持早期陶燈存在及該件長9.8cm／高2.7cm；沒有目視館圖，不複製形狀。HUC尺寸單位存疑不可採用。Lund與Peppard支持lampas可能火把，沒有給足一套確定原器工程圖；本稿不把火把概念宣稱為唯一無疑原物。

陶燈與油瓶有實際開口、內壁和內底；任何燈芯通道／注油孔若製作必須真通、能看見或以雙向射線證明，不用貼黑面冒充。未取得精確形制可用簡單原創實用容器，不增加晚期十字飾紋或假古銘文。火把概念使用明列選定的桿、握持與可吸油材料，靜置於**現代支架**，支架與桿有實接觸、承托／止滑；不是直接站在尖底或與托架穿透。可先採不點火狀態，燃燒外觀與時數不是幾何QA目標，不加入加油／點火操作指示。三件均靜態，無需拆層；油與燈的比喻象徵不由模型定義。

## 交付與檢查

在`.qa/parables-prototype`保存可編輯原型來源、可重跑腳本、三件GLB及JSON。從**實際匯出的GLB**新匯入渲染，記錄source／GLB／PNG SHA256、相機及所有隱藏狀態；不得用舊模型圖片充數。每件至少前／側／俯／底，空腔另有近距內部與實際剖面；拆示若有另給拆開、還原和接觸視角。暗內底若看不清要照實說，提供成對射線，不能稱照片已清楚見底。

量測source與GLB實際bbox、公尺、有限座標、法線、閉合正體積（開口器皿的材質體仍應閉合）、真壁／底厚、接觸實面積／穿透、99+1逐件數與間距。接觸不能由AABB推定，凹ngon應採實際評估三角面。非體積的現代材質根線須明列，不能混算為實體根。若有移層，逐頂點確認受控後代、固定0、還原及20路徑取樣。列清有限取樣限制，不宣稱材料強度或完整連續碰撞證明。先交設計疑點或必要調整，再執行隔離製作；正式整合仍待root接受。
