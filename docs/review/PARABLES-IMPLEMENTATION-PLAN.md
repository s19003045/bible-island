每章13位居民、8組POI／16站位，依獨立seed、速度0.85–1.15、個別決策、容量預約、分離避讓與平滑朝向；20%合格相遇短談沿用，不用共用行為時計或random walk。無名一般第一世紀成人與孩童模型按既有衣裝範圍重用，不認證原人物面容、民族制服或童女年齡。三位可交談居民分田邊工作、牧養日常及照明準備；每人三題、一追問與三個親子cue，實際24cue先由`personForMode`匯出完整覆核，再生成。

## 教具與模式

三件Blender原創現代比較，須先隔離原型、幾何及實際GLB渲染檢視，接受後才整合正式`.blend`。見 [教具設計](PARABLES-ASSET-BRIEF.md)。場景仍須有真實生活細節與動態羊，不能只靠三塊比較盤完成島嶼。

一般模式連讀講述處境、敘事與解說；觀察不代填讀經。親子先看物件，再回答聽見與解明、尋回後同樂、十人都睡與預備的問題；不將答題者判為壞土、罪人或愚拙者。研讀先開資料，分別辨識經文、原研究及現代剖示／布局；lampas研究的器型分歧保留，不讓單一陶燈變成原物證明。模式／分章／時刻切換取消舊對話及聲音，舊島札記、觀察與進度隔離；經文皆YouVersion312CSBT。
