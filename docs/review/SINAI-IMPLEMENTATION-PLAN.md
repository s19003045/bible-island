# 西奈與曠野：接續實作決定

2026-11-16。接續第十座約瑟島之後；此文件是施工計畫，不是第十一座已完成或已發佈的聲明。研究底稿見 [經文與比較界線](SINAI-RESEARCH-START.md)。

## 分章順序與角色

保留 `manna`／`water`／`mountain` 的原 ID，依出 16、17、19–20 的敘事順序排序。入口、一般故事游標、親子題與研讀項同步，切章結束舊對話及步行，不把三個營地拼成同日真實地圖。各章保留一個教具與一位無名綜合角色：收取食物的居民、缺水路程的同行者、山前預備的家人；不以扮演摩西、亞倫或神來聲稱第一手見證。

每章沿用 13 位 NPC、8 組 POI／16 個容量位置的密度基準。沿用個別 seed、速度與時鐘、容量預留、分離避讓、平滑轉向和短暫交談；不使用群體計時器或 random walk。明確映射 `wilderness-resident`、`wilderness-woman`、`wilderness-child`，不落入第一世紀 `resident` 預設，不借祭司制服或約瑟島埃及衣裝。現有 Blender 衣裝本身已是原創類型選擇；不為宣稱新品而單純換色。

## 三個分層空間

1. **嗎哪**：汛曠野的普通帳棚、清晨地表、收取與準備食物的位置，遠處層次和同行居民。沒有預先完成的會幕或約櫃。白色薄片只供觀察，不做現代物種認證，也不以囤積最多者獲勝。
2. **供水**：利菲迪姆缺水處境與何烈磐石的教學背景。岩面及可見流路在指定路線之外，玩家在安全觀察區走訪、提問與看教具；不設玩家擊打兩次的操作，不放暗管或機械剖面解釋神蹟。民 20 在另一張對讀卡列清不同地名、吩咐與後果。
3. **山前**：前景營地、山腳觀察帶、後景高山和雲煙層次。山址與地形原創，不用現代候選山的等高線指認。界線使用明確標示的現代教學視覺層，實際導航區不開放上山或越界處刑遊戲；沒有先到手的石版、修道院或神像。

以公尺尺度規劃成人、棚架與道具；近處地表加密並與碰撞坡面對齊。大岩、棚繩、容器和山腳代理須擋住通行，觀察桌南側保留至少一條可供實際角色控制器與動態 NPC 同時通行的路。新場景禁止以放大微縮模型代替地形與生活區。

## Blender 教具預製

`scripts/blender/sinai-props.py` 由有界限素材工作預製，尚未接入主建置或匯出到正式 `public/models`：

- `sinai-manna`：三個相同普通空心容器，以一份與兩份比較。薄片形狀、大小、數量及容器器形明載教學選擇；不以碗形或未測量的體積宣稱古代俄梅珥標準。
- `sinai-water`：實體岩面、外露水路與接水位置的原創比較。水只在外表面，不設暗藏機構。
- `sinai-boundary`：山、山腳與遠站營地空間圖；`sinai-boundary-guide` 為獨立的現代色帶圖層，可抬起作教學比較，不能解釋為古代圍欄。

三件各少於三萬三角，實際 Blender 匯出、內壁／厚度、比例與材質需要檢查；保存來源、報告與 GLB，場景及近景共用。預製腳本或隔離渲染不能冒充全專案 `.blend`／正式 GLB 已更新。

## 學習、音訊與完成條件

親子問題分別聚焦每日需要／安息日、供水敘事的處境、山前預備與界限；不用飢渴或害怕者作嘲笑題。一般按三章讀經；研讀分開經文描述、器物比較與視覺復原。所有經文入口維持 YouVersion 312 CSBT，逐章／逐段開啟；器物觀察、已讀經文與各模式資料分開保存。

三位角色各八段一般／親子語音，先穩定台詞與模式資料，再使用已驗證 ACTIVE 聲音一次生成。預設音訊格式、實際回傳時間碼、原速度 MP3 與雜湊沿用既有流程；生成錯誤後依 narrator 技能取得下一次生成授權，不能自動改聲或重試。每章有獨立環境與腳步聲，現代配樂清楚標示，可安靜探索。

新增整合測試要涵蓋章序與舊 ID、三幕合法區／山前禁止區、240 秒 NPC 決策／容量／間距／交談、穿過動態人群的實際控制器與多更新率接地、真實 GLB 內部及拆合、抵達視線、服裝與 24 段精確配音、跨島跨模式隔離。另做真實瀏覽器走訪／近景與情境對話，檢視正式入口、三種模式、CSBT 和 console，成功發佈同一個私人 Sites 後才把第十一座標為已交付。其他十三座及既有人工補驗的範圍不能被刪除。
