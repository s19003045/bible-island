# 出埃及三件 Blender 觀察物

2026-11-16。五島十四項既有觀察物都有 Blender 近景；其中十三項實體展品同時用於場景，渡海剖面只供觀察，大場景水體與自主前進隊伍另行保留。這是器物批次完成，不代表人物寫實化、全部手動驗收或十九座詳細島嶼已完成。

## 模型與來源

使用已校驗的 Blender 4.5.16 LTS，新增 `scripts/blender/exodus-props.py`，經同一流程建立網格、顏色、群組、可編輯場景與三份本機 GLB。材料與推定表見 [素材說明](../../assets/blender/README.md)。

- 單格無底磚模有四側、延伸握把與木紋，模內泥磚與旁邊的泥磚可比較草料。抬起模框，泥磚留在原位。[Met 木磚模 25.3.108](https://www.metmuseum.org/art/collection/search/568270)與 [Emery 的工法研究](https://escholarship.org/content/qt7v84d6rh/qt7v84d6rh.pdf)提供類型及技術背景；沒有複製影像或網格，也不由館藏年代指認出埃及年代。約 0.12 m 的教具高度、木種及配比均為選擇。
- 薄餅採不規則邊緣、厚度與烘烤色差；布包覆住有內壁與底的和麵器皿，另有杖與繩結。布包可移開／還原。首輪預覽發現木器穿出布面，已修正外覆曲面，並加入實際幾何驗證。約 0.283 m 的高度、器形及材質是教學安排；物件用於對讀[出 12:8–14、34、39 · CSBT](https://www.bible.com/zh-TW/bible/312/EXO.12.CSBT)的不同片段，不當作同一瞬間的家庭照片。
- 渡海剖面為兩個封閉、有波紋與透明度的水體，留出中央乾地及三個提示方向的小木人。對照[出 14:21–22、29–31 · CSBT](https://www.bible.com/zh-TW/bible/312/EXO.14.CSBT)，不給出現代海域、人口或量度的判定；不採統一縮尺。較高的初始視角方便觀察乾地，仍可旋轉。

模型共用原近景 renderer 與資產快取，支持失敗時的本機備用模型；磚模與布包的備用版本也保留拆合。三段敘事、可步行區、資料隔離、三種學習模式、人物對話與十八份錄音均維持原語意。經文連結仍為 YouVersion CSBT。

## 驗證

全部 **119 項測試**通過；24 主題／74 探索點、語法、正式建置與離線封裝通過。新增四項直接讀取實際 GLB：

1. 由射線確認模框中間／底部沒有隱藏底板，抬模不移動泥磚，復位無漂移。
2. 由射線確認碗內底，並在三個高度、每層十六個方向確認布面位於碗外；移開布包不移動木器。另由實際預設取景位置射向碗內底，確認第一個命中面就是碗底，避免「有位移卻仍遮住」的操作。
3. 水體三角網格的每條焊接邊皆由兩個面共用，左右不侵入中央乾地，小人腳底貼合地面。
4. 各章實體展品真正替換、遮擋物更新、合法接近路線；渡海靜態剖面沒有取代持續前進的隊伍。

十五場景 `.blend` 已再次用 Blender 開啟，確認模框、布包、器皿、水體階層與五種既有骨架動作。磚模 4,076 三角形／204,944 bytes；行路物件 20,540／514,896；渡海剖面 10,336／266,936。實際雜湊以 [建置報告](../../assets/blender/build-report.json)為準。離線試閱 34,332 KiB，含十五份 GLB 及十八份 MP3。

三件 Blender 預覽已檢視，並修正穿插、薄餅堆疊、腳底／頸部接合與剖面取景。影像為 `.qa/blender-brick-mould.png`、`.qa/blender-passover-kit.png`、`.qa/blender-crossing-ground.png`。本機已沿路走到磚模旁，開啟觀察視窗並實際抬起／還原木框；可見泥磚留在框下，畫面說明與來源入口正確。截圖 `.qa/exodus-mould-separated.png`。沒有為拍攝改動人物動畫偏好。

再沿第二章家屋入口走到布包旁，實際操作後發現初版的移位仍遮住碗口；已增加移開距離並提高初始取景，加入上述視線測試。兩件近景重用的 canvas renderer generation 均為 `1`；console error／warning 為空。修正後完整回歸仍為 119 項通過，正式／離線建置已更新。Sites 初批已發佈，修正與最後畫面於本輪接續記錄，不將初版操作當成修正後的畫面證明。
