## 2026-11-17：教具草案與閱讀場景的接法

已另寫[三件教具有界稿](NATIVITY-ASSET-BRIEF.md)，請既有代理只作文字／幾何可行性覆核，仍未授權製模。補核未取得的考古平面及原圖繼續保留缺口；原創教具的尺寸不能冒稱由它們測得。史料文字覆核未發現需阻擋的經文誤置，但這是有界內部覆核，不是獨立專家簽核，也未審台詞或實際幾何。

後續主場採三個有區別的閱讀觀察區：第一章為原創鄉郊家屋外緣與較遠牧地，第二章為拿撒勒日常家屋的形式比較，第三章為成年返鄉處境的公共街區、聚集與另置木料比較。不得把三者做成一日可走完的測繪路線，也不能只把同一片展示桌地板換名字。近、中、遠景各有街徑、院落／梯田、家屋高低與山地背景；人物、屋門、樹木及全尺寸空槽維持同一公尺尺度，家屋教具則清楚標約1:10。

第一章擬分三個互斥閱讀時刻：路2:4–7的家庭行程與降生／安放，2:8–14牧人在野外聽見，2:15–20前往、看見與述說。野外時刻鎖夜間；其他未給時刻不宣稱精確時辰。只用無名綜合居民和已有羊模型提供生活比較，不標作具名人物原貌，不以發光人形、星體模擬或槽旁動物認證消息的視覺形態。若需要可見嬰孩，仍須另作專門建模決定，不能暗中用包裹或縮小成人替代。馬太的來訪與後續仍是分卷閱讀入口，沒有博士同時站在路加馬槽旁的場景。

第二章擬分成長（路2:39–40）、另地節期閱讀（2:41–50）與返回（2:51–52）。本輪若只製作拿撒勒主場，第二時刻必須明示是在此對讀耶路撒冷事件，而非把同一屋子改名聖殿；可透過既有希律聖殿島比較空間，但不自動完成別島進度。教師、十二歲聽與問及父母尋找仍由經文交代，不在家屋內演成授徒課堂。第三章只有可6:1–6成年返鄉窗口，無名居民解說當地聽眾的問句和反應；木料接合另作明示的現代構造比較。
