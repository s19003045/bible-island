# Blender 素材與原十九座島的接續範圍

2026-11-16。此文件維持本次 Goal 的完整範圍：先部署既有五島，再完成群山／流雲，接著用 Blender 製作並替換 NPC 與重點器具，最後完成其餘十九座島。不得把已有的微縮模型或只有文字卡更新視為詳細島升級完成。

## Blender 的交付條件

1. 保存可編輯 `.blend`、可重跑的製作腳本、匯出的 GLB 與來源／比例說明。確認實際經 Blender 開啟、製作及匯出，不只建立空檔或命名佔位。
2. NPC 需有成人身形、可辨識五官、手部／鞋履／衣料層次、合乎年代與職分的服裝。建立行走、停留、觀望、工作和交談動作；保留原有 POI seed、容量、避讓與對話語意。
3. 器具先處理五島現有十四項觀察物的細節、材質與構造，逐項替換場景及近景。把史料給出的尺寸／材料，與形制推定及教學剖面分開標示。
4. Three.js 使用可追溯的本機 GLB 載入、合理的遠近細節與快取；名稱、互動距離、碰撞代理、來源、選單及學習事件不能隨美術替換失效。檢查 GLB 幾何、法線、比例、動畫與資源釋放，並在實際畫面檢視品質。

## 接續 NPC 素材

第一輪成人細化已接入本機並發佈至 Sites：改善肩口／手部／腳掌、實際距離步態與坡面足部 IK，並提供無鬆披布工藝版本。範圍為耶路撒冷與希律的一般成人；正式頁已確認新工藝人物、場景提問及 CSBT 連結。這不代表全體 NPC、其他性別／年齡／持物或舊約職分已完成。驗收另見 [成人細化](review/BLENDER-RESIDENT-REFINEMENT.md)。

第二輪已實際製作孩童與提水居民並接入耶路撒冷、發佈至 Sites：原有四位孩童使用獨立臉部、頭身四肢比例和短步幅；提水者使用彎肘／彎指與空心陶壺，五種動作維持握持。實際 GLB 比例、上下坡腳底、握把接觸、場景及 128 項回歸已通過；本機與正式頁確認新持物者、問答與 CSBT。瀏覽器與發佈結果見 [孩童與持物驗收](review/BLENDER-CHILD-AND-CARRIER.md)。

第三輪補入十種衣裝／身形：婦女、曠野居民／婦女／孩童、一般祭司、第一聖殿居民／婦女、歌者、銅作工匠與製磚勞作者。五島近處人物皆已接入專用 GLB；十四種人物與十四項觀察物合計二十八份 GLB。這是五島人物第一輪整合，遠景保留較輕模型，人物仍有風格化特徵，不能稱為照片級復原或全體古代服裝定論。此批的驗收及發佈記錄見 [年代與職分人物](review/BLENDER-PERIOD-CHARACTERS.md)。

接續下表十九島；五島人物仍依以下條件維護，不因素材替換就略過既有希律近景及渡海剖面的手動補驗。

1. 細化第一世紀一般成人的臉部／眼瞼、衣袖／手部接合、衣料及涼鞋，改善步態接地；以耶路撒冷、希律一般成年居民驗證，不把服裝直接移植舊約。
2. 加入符合既有角色的服裝及持物變體，再處理孩童的身形、動作及搬水持物。職分、服裝依據與推定均需可追溯；不只換顏色就宣稱已完成角色差異。
3. 會幕、所羅門及出埃及各自處理年代與職分，尤其祭司及其他居民的差別。服裝取捨和角色對話處境相符，不替換或改造既有經文／錄音語意。
4. 原 POI、個別 seed／時鐘／速度、避讓、3–6 秒交談及樓梯控制繼續由現有系統處理；細節遠近切換保留效能上限。替換不能造成角色瞬移、點不到對話、持物脫手或腳底長時間漂浮。
5. 驗證五種動作、不同角色的尺寸、步態足底與持物、獨立骨架、場景對話及資料隔離；對實際畫面完成檢視及 Sites 發佈，再將該批標為完成。既有希律近景及渡海剖面的手動補驗一併接續。
