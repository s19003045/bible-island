# 讀聖經順起來：產品與實作規劃

## 核心目標

讓讀者透過空間與古代日常理解經文中的位置、動作與處境，再回到經文本身。島嶼是主題入口；島上的物件是具體問題；主題間連線代表故事、地點、人物或閱讀關係。

## 第一版已實作

1. 24 座島、74 個探索點，含經文、提問、三種閱讀深度及復原說明。
2. 八個核心場景：會幕、所羅門聖殿、第二聖殿初期、希律擴建階段、出埃及、過約旦河、耶路撒冷與宣教港口。
3. 其他十六個場景使用可重用的營地、家屋、山地、田地、城防、港口與聚會零件，並提供各主題的經文探索。
4. 全景、近景、剖面、熱點、導覽、主題關係、篩選與深連結。
5. localStorage 足跡與收藏，無後端與帳號系統。
6. 桌機與手機介面、可用鍵盤操作的完整內容清單、WebGL 失敗的文字閱讀。

## 內容與關係

八座核心島與十六座延伸島共用同一份 `content.js`。關係目前分為故事接續、同地異時、地理相鄰、空間比較、主題比較、人物與書信、背景延伸及閱讀延伸。

聖殿主線：會幕 → 所羅門聖殿 → 歸回後的第二聖殿 → 希律擴建後的第二聖殿。模型沒有將會幕的約櫃直接放入新約時期聖殿。

## 閱讀體驗

每次閱讀以「一個問題 → 一個物件 → 一段經文 → 一個相關主題」為單位。親子模式側重觀察與提問，一般模式說明故事背景，研讀模式再補入文本比較、來源與不確定性。

## 3D 技術

Three.js、PerspectiveCamera、OrbitControls。以共享幾何與 InstancedMesh 集中繪製相同種類零件；以 Raycaster 處理模型點選，DOM 投影標籤提供清楚文字與鍵盤入口。靜態陰影按需更新；持續慢幀降低像素比例；背景分頁暫停更新；遵循 prefers-reduced-motion。場景不需要外部模型或即時 API。

## 已知範圍與後續階段

- 第一版是可操作的微縮教學場景，尚非一比一步行、VR 或考古精密復原。人物是場景示意，未加入自主行走與導航 AI。
- 保羅島展示宣教交通與群體背景；逐次宣教旅程的真實地圖、航路時間軸與城市獨立模型列入下一階段。
- 時代控制為敘事階段篩選，沒有強制替爭議事件指定西元年份。
- 下一階段優先：實際地圖與高度剖面、保羅分次路線、更多獨立場景模型、專家審閱與逐物件來源。
- 再下一階段：本地經文授權與版本選擇、經審閱的旁白、教師導覽單與課程組合。雲端同步需另行規劃個資與帳號。

## 驗證與交付

內容驗證確保 ID、熱點、關係和經文欄位完整；單元測試覆蓋搜尋、複合篩選、導覽邊界與損壞或不可用的瀏覽器儲存。另以瀏覽器確認 3D 全景、會幕探索／剖面、閱讀模式、主題搜尋、收藏、時間篩選及窄螢幕布局。
